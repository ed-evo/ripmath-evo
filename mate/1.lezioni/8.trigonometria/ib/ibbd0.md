# Differenze fra reciproca di una funzione e funzione inversa

Si definisce **reciproca di una funzione** la funzione che moltiplicata con quella di partenza mi dà come risultato $$1$$. Esempio: data la funzione

$$\textcolor{red}{y = e^x}$$

la reciproca della funzione è

$$
\textcolor{red}{y = \frac{1}{e^x}}
$$

Invece la **funzione inversa** di una funzione data è quella che si ottiene scambiando fra loro dominio e codominio (in pratica scambiando la $$x$$ con la $$y$$).

Esempio: data la funzione

$$\textcolor{red}{y = e^x}$$

la funzione inversa è [Calcoli](ibbd0a.html)

$$\textcolor{red}{y = \log x}$$

> Matematicamente la definizione è:
>
> Una funzione è inversa di un'altra se la funzione composta vale $$x$$
>
> $$\textcolor{red}{f(x) \text{ è inversa di } g(x) \text{ se } f[g(x)] = x}$$
>
> cioè
>
> $$\textcolor{red}{\log(e^x) = x}$$
>
> od anche
>
> $$\textcolor{red}{e^{\log x} = x}$$

Le funzioni inverse delle funzioni trigonometriche sono:

- di $$\textcolor{red}{y = \operatorname{sen} x}$$ è $$\textcolor{red}{y = \operatorname{arcsen} x}$$
- di $$\textcolor{red}{y = \cos x}$$ è $$\textcolor{red}{y = \arccos x}$$
- di $$\textcolor{red}{y = \operatorname{tang} x}$$ è $$\textcolor{red}{y = \operatorname{arcotang} x}$$

Verranno usate esclusivamente nella soluzione delle equazioni trigonometriche fondamentali quando il valore dell'angolo non è nella [tabella dei valori](ibef.html) trigonometrici:
