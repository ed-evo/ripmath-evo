# Terza formula di Werner

Partiamo dalle due formule di addizione e sottrazione per il coseno e sommiamo in verticale.

> i due termini uguali $$\textcolor{blue}{\text{sen } \alpha \text{ sen } \beta}$$ avendo segni contrari si annullano e spariscono.

$$\textcolor{red}{\cos (\alpha + \beta)} = \textcolor{red}{\cos \alpha \cos \beta} - \textcolor{blue}{\text{sen } \alpha \text{ sen } \beta}$$
$$\textcolor{red}{\cos (\alpha - \beta)} = \textcolor{red}{\cos \alpha \cos \beta} + \textcolor{blue}{\text{sen } \alpha \text{ sen } \beta}$$

$$
\textcolor{red}{\cos (\alpha + \beta) + \cos (\alpha - \beta) = 2 \cos \alpha \cos \beta}
$$

Ricaviamo $$\textcolor{red}{\cos \alpha \cos \beta}$$ ed otteniamo la terza formula di Werner:

$$
\textcolor{red}{\cos \alpha \cos \beta = \frac{\cos (\alpha + \beta) + \cos (\alpha - \beta)}{2}}
$$
