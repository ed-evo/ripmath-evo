# Logaritmi a base maggiore di uno

Cerchiamo di fissare il problema con degli esempi numerici: consideriamo dei logaritmi a base $$3$$

prima positivi
[$$\log_3 3 = 1$$ perché $$3^1 = 3$$]{.text-blue}
[$$\log_3 9 = 2$$ perché $$3^2 = 9$$]{.text-blue}
[$$\log_3 27 = 3$$ perché $$3^3 = 27$$]{.text-blue}

................

poi negativi
[$$\log_3 1/3 = -1$$ perché $$3^{-1} = 1/3$$]{.text-blue}
[$$\log_3 1/9 = -2$$ perché $$3^{-2} = 1/9$$]{.text-blue}
[$$\log_3 1/27 = -3$$ perché $$3^{-3} = 1/27$$]{.text-blue}

................

in mezzo avremo
[$$\log_3 1 = 0$$ perché $$3^0 = 1$$]{.text-blue}

mettiamo in ordine secondo il valore dell'argomento

[$$\log_3 1/27 = -3$$]{.text-red}
[$$\log_3 1/9 = -2$$]{.text-red}
[$$\log_3 1/3 = -1$$]{.text-red}
[$$\log_3 1 = 0$$]{.text-red}
[$$\log_3 3 = 1$$]{.text-red}
[$$\log_3 9 = 2$$]{.text-red}
[$$\log_3 27 = 3$$]{.text-red}

Possiamo osservare che quando la base è $$3$$:

- quando l'argomento è minore di $$1$$ il valore del logaritmo è negativo e diventa sempre più piccolo man mano che l'argomento si avvicina a zero
- quando l'argomento vale uno il logaritmo vale zero
- quando l'argomento è maggiore di uno il logaritmo è positivo e cresce al crescere dell'argomento

> Come abbiamo preso la base $$3$$ potevamo prendere $$2, 4, 5, 6, \dots$$ Queste regole sono valide per tutte le basi maggiori di $$1$$, ma torneremo ancora sull'argomento quando faremo il grafico della funzione logaritmo
