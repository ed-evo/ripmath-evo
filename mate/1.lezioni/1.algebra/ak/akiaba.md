# Calcoli

Devo risolvere il sistema

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
(x-3)^2 \ge x^2 - 3x + 2
\end{cases}
}
$$

Sviluppo la terza disequazione

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
x^2 - 6x + 9 \ge x^2 - 3x + 2
\end{cases}
}
$$

Porto i termini prima del segno di disuguaglianza

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
x^2 - 6x + 9 - x^2 + 3x - 2 \ge 0 
\end{cases}
}
$$

Sommo i termini simili

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
- 3x + 7 \ge 0 
\end{cases}
}
$$

Cambio di segno e verso della terza

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
3x - 7 \le 0 
\end{cases}
}
$$

Porto il $-7$ dopo il segno di disuguaglianza

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
3x \le 7 
\end{cases}
}
$$

Divido la terza per $3$

$$
\textcolor{blue}{
\begin{cases} 
x^2 - 3x + 2 \ge 0 \\
x - 3 \ge 0 \\
x \le 7/3 
\end{cases}
}
$$
