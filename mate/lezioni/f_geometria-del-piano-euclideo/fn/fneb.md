# Approssimazione per eccesso

Significa approssimare il numero con valori più alti.

Dato il numero decimale $\textcolor{red}{1,414293\dots}$ per approssimare per eccesso basta scrivere il numero fino alla cifra a cui si deve approssimare togliendo gli altri termini ed infine **aumentando di $1$ l'ultima cifra**.

- Approssimato per eccesso alla prima cifra: $\textcolor{red}{1 + 1 = 2}$
- Approssimato per eccesso alla seconda cifra: $\textcolor{red}{1,4 + 0,1 = 1,5}$
- Approssimato per eccesso alla terza cifra: $\textcolor{red}{1,41 + 0,01 = 1,42}$
- Approssimato per eccesso alla quarta cifra: $\textcolor{red}{1,414 + 0,001 = 1,415}$
- Approssimato per eccesso alla quinta cifra: $\textcolor{red}{1,4142 + 0,0001 = 1,4143}$
