# Equazioni trigonometriche fondamentali

Tutte le equazioni trigonometriche si possono ridurre ai $3$ tipi fondamentali

- [$\operatorname{sen} x = h$](iccaa.html) con [$\textcolor{blue}{-1 \le h \le +1}$]{.text-blue}
- [$\operatorname{cos} x = n$](iccab.html) con [$\textcolor{blue}{-1 \le n \le +1}$]{.text-blue}
- [$\operatorname{tang} x = p$](iccac.html) con $p \in \mathbb{R}$
