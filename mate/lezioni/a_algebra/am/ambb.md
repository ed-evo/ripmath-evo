# Grafico della funzione esponenziale quando la base è compresa tra $0$ ed $1$

> Costruiamo il grafico considerando la base $\frac{1}{2}$: infatti quando la base è compresa tra $0$ ed $1$ tutte le curve esponenziali ottenute con qualunque base hanno le stesse caratteristiche

Voglio costruire il grafico della funzione

$$
\textcolor{blue}{y = \left(\frac{1}{2}\right)^x}
$$

Lo costruiamo per punti: diamo dei valori a $\textcolor{blue}{x}$ ed otteniamo $\textcolor{blue}{y}$;

| $\textcolor{blue}{x}$ | $\textcolor{blue}{y}$ |
| :---: | :---: |
| $\textcolor{red}{4}$ | $\textcolor{red}{\frac{1}{16}}$ |
| $\textcolor{red}{3}$ | $\textcolor{red}{\frac{1}{8}}$ |
| $\textcolor{red}{2}$ | $\textcolor{red}{\frac{1}{4}}$ |
| $\textcolor{red}{1}$ | $\textcolor{red}{\frac{1}{2}}$ |
| $\textcolor{red}{0}$ | $\textcolor{red}{1}$ |
| $\textcolor{red}{-1}$ | $\textcolor{red}{2}$ |
| $\textcolor{red}{-2}$ | $\textcolor{red}{4}$ |
| $\textcolor{red}{-3}$ | $\textcolor{red}{8}$ |
| $\textcolor{red}{-4}$ | $\textcolor{red}{16}$ |

Ora metto i punti trovati in un grafico.

> **Nota:** il punto $(-4, 16)$ non è stato messo.

Ed infine li congiungo con una riga continua.

Sarà comunque una curva poco usata.
