Calcolare la seguente espressione utilizzando, ove possibile, il calcolo delle potenze

(a2)3 · [(a3)2 : (a4)2]2 +(-a)2 =

Inizio dalle parentesi tonde: sono potenze di potenze: eseguo il prodotto fra gli esponenti, nell'ultima paentesi la base e' mnegativa, ma essendo l'esponente pari ottengo come valore della potenza un valore positivo

a2·3 · [a3·2 : a4·2]2 + a2 =

= a6 · [a6 : a8]2 + a2 =

Ora devo risolvere l'operazione entro parentesi quadra: e' un quoziente, faccio la differenza fra gli esponenti

= a6 · [a6-8]2 + a2 =

= a6 · [a-2]2 + a2 =

Eseguo la potenza di potenza: moltiplico gli esponenti

= a6 · a-2·2 + a2 =

= a6 · a-4 + a2 =

eseguo il prodotto fra le potenze sommando gli esponenti

= a6-4 + a2 =

= a2 + a2 =

ora sommo i due monomi ed ottengo

= 2a2
