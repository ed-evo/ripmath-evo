apprendimento

Calcolare la seguente espressione

(x2y · x3y2)3 : (x5y5 : x3y2)2 =

Inizio dalle parentesi tonde:
Nella prima parentesi c'e' un prodotto di potenze: sommo gli esponenti delle lettere uguali
Nella seconda parentesi c'e' un quoziente di potenze: eseguo la sottrazione fra gli esponenti delle lettere uguali


= (x2+3y1+2)3 : (x5-3y5-2)2 =

= (x5y3)3 : (x2y3)2 =

Ora devo fare le potenze di potenza: moltiplico gli esponenti

= x5·3y3·3 : x2·2y3·2 =

= x15y9 : x4y6 =

Ora eseguo la divisione fra le potenze sottraendo gli esponenti

= x15-4 y9-6 =

= x11 y3



ora chiudi e passa ad un altro gruppo di esercizi
