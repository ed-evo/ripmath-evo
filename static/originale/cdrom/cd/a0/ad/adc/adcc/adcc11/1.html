Risolvere la seguente equazione

   (x - 2)(x + 1) - (x - 3)(x + 2) = (x - 2)(x - 3) - x2 + 3

   x2 + x - 2x - 2 - (x2 + 2x - 3x - 6) = x2 - 3x - 2x + 6 - x2 + 3

   x2 + x - 2x - 2 - x2 - 2x + 3x + 6 = x2 - 3x - 2x + 6 - x2 + 3

   x2 - x2 - x2 + x2 + x - 2x - 2x + 3x + 3x + 2x = 2 - 6 + 6 + 3

    5x = 5

    x = 1
