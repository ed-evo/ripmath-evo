Risolvere la seguente equazione

   (2x - 1)2 + 16 = (2x + 1)2

sviluppo i quadrati

   4x2 - 4x + 1 + 16 = 4x2 + 4x + 1

porto i termini con la x prima dell'uguale ed i termini senza la x dopo l'uguale; chi salta l'uguale cambia di segno
ordino anche le x secondo l'esponente

   4x2 - 4x2 - 4x + 4x = -1 - 16 + 1

sommo i termini simili

      0 = - 16

poiche' 0 non puo' essere uguale a -16 l'equazione e' impossibile
