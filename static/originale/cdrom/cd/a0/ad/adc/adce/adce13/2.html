a ≠ 0

scrivo le condizioni a destra solo con queste condizioni posso risolvere l'equazione

applico mentalmente il secondo principio per eliminare i denominatori

moltiplico

    ax + bx + a2 + ab - (ax - bx - a2 + ab) = ax + a2 + 2ab

Sposto i termini con la x prima dell'uguale e quelli senza la x dopo l'uguale: chi passa l'uguale cambia di segno (prima sposto poi sommo, cosi' risparmio un passaggio)

    ax + bx- ax + bx - ax = a2 + 2ab - a2 - ab - a2 + ab

sommo i termini simili
