Risolvere e discutere la seguente equazione

    (3a - 1)(b + 2)x = 0

l'equazione e' gia' a posto: seno evidenziati e scomposti i termini davanti alla x

Per poter applicare il secondo principio controllo pongo i termini davanti alla x diversi da zero

    (3a - 1)≠ 0   →   a ≠ 1/3
    (b + 2) ≠ 0   →   b ≠ -2

   se a ≠ 1/3 e b ≠ -2 posso applicare il secondo principio ed ottengo la soluzione x = 0

   se a = 1/3 oppure (oppure significa l'uno o l'altro o tutti e due) b = -2   →   0x = 0 equazione indeterminata

raccolgo i risultati


se a ≠ 1/3 e b ≠ -2   →   x = 0

se a = 1/3 equazione indeterminata
 
se b = -2 equazione indeterminata
