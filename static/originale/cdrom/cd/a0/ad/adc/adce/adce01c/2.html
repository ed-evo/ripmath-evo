Risolvere e discutere la seguente equazione

    ax - b = 0

Sposto il termine noto dopo l'uguale

    ax = b

    Per la a ho due possibilita'

  • se a ≠ 0 posso applicare il secondo principio di equivalenza e quindi ottengo
    ax

    a     		  =   b

    a     		  calcolo ed ottengo   x   =   b

    a


  • se a = 0 non posso applicare il secondo principio di equivalenza e quindi sostituisco 0 alla a nell'equazione ed ottengo
        0x   =   b

              adesso dipende dalla b

    •        se b ≠ 0 allora ho 0x   =   b
              siccome questa uguaglianza non e' mai valida per b ≠ 0 allora l'equazione e' impossibile

    •         se b = 0 allora ho 0x   =   0
              siccome questa uguaglianza e' valida per qualunque valore di x allora l'equazione e' indeterminata


raccolgo i risultati (finora non l'abbiamo mai fatto perche' i risultati erano semplici)

        Se a ≠ 0   →   x   =    b

 a
        Se a = 0 e b ≠ 0   →   0x   =   b   equazione impossibile
 
        Se a = 0 e b = 0   →   0x   =   0   equazione indeterminata
