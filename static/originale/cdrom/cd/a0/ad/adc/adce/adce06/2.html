Risolvere e discutere la seguente equazione

    a(x + 1) + 3bx = b(1 - 2x) + ax

eseguo le moltiplicazioni

    ax + a + 3bx = b - 2bx + ax

Sposto i termini con la x prima dell'uguale e quelli senza la x dopo l'uguale: chi passa l'uguale cambia di segno (potrei prima sommare i termini simili, ma cosi' risparmio un passaggio)

    ax - ax + 3bx + 2bx = b - a

sommo i termini simili

    5bx = b - a

    5 e' sempre diverso da zero; per b ho due possibilita'

  • se b ≠ 0 posso applicare il secondo principio di equivalenza e quindi ottengo
    5bx

    5b    		   =   b - a

    5b    		   →   x   =   b - a

    5b


  •    se b = 0   →   0·5x = 0 + a   →   0x = a

      ho due possibilita'
    • se a ≠ 0   →   0x = a equazione impossibile
    • se a ≠ 0   →   0x = 0 equazione indeterminata
