Risolvere e discutere la seguente equazione

    2ax - 3(a - 1) = a(x - 2)

eseguo le moltiplicazioni

    2ax - 3a - 3 = ax - 2a

Sposto i termini con la x prima dell'uguale e quelli senza la x dopo l'uguale: chi passa l'uguale cambia di segno

    2ax - ax = 3a + 3 - 2a

sommo i termini simili

    ax = a + 3

    per, a ho due possibilita'

  • se a ≠ 0 posso applicare il secondo principio di equivalenza e quindi ottengo
    ax

    a    		   =   a + 3

    a    		   →   x   =   a + 3

    a


  • se a = 0 non posso applicare il secondo principio di equivalenza e quindi sostituisco 0 ad a nell'equazione ed ottengo
        0x = 0 + 3            0x = 3

    siccome non esistono valori di x che rendano valida l'uguaglianza l'equazione e' impossibile
