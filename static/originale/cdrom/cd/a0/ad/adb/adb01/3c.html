Verificare la validita' della seguente identita'

a2(a3 - 1) + a(1 - a4) + a(a - 1) + a = a2 : a + a(a - 1) + a(1 - a)

eseguo le moltiplicazioni e le divisioni sia prima che dopo l'uguale;

a5 - a2 + a - a5 + a2 - a + a = a + a2 - a + a - a2

sommo algebricamente tra loro i termini simili sia prima dell'uguale che dopo l'uguale ed ottengo

a = a

quindi l'identita' e' valida
