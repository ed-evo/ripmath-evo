In alcuni libri di testo, quando vi sono scomposizioni di Ruffini successive, invece di utilizzare uno schema per ogni divisione ho visto utilizzare uno schema unico quale quello qui di fianco riportato
  1 -1  -8    +12
+2   +2 +2 -12
  1 +1 -6 //
+2   +2 +6
  1 +3 //












Personalmente, per non fare confusione, preferisco utilizzare piu' schemi successivi

  1 -1  -8    +12
+2   +2 +2 -12
  1 +1 -6 //








  1  +1    -6
+2   +2 +6
  1 +3 //






Comunque tu segui il metodo che ritieni piu' adatto
