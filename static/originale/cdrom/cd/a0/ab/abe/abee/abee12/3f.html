Scomporre

    x3 + 3x2 + 3x +1 - 27a3 =

i primi quattro termini sono il cubo di un binomio
il quinto e' il cubo di -3a

quindi posso scrivere

= (x + 1)3 - 27a3 =

Adesso posso considerarli due termini e scomporre come differenza di due cubi

= [(x+1) - 3a] [(x + 1)2 + 3a(x+1) + 9a2] =

eseguo i calcoli entro le parentesi quadre

= [(x + 1) - 3a] [x2 + 2x + 1 + 3ax + 3a + 9a2] =

faccio cadere la parentesi tonda

= [x + 1 - 3a] [x2 + 2x + 1 +3ax + 3a + 9a2]

sostituisco le tonde alle quadre

= (x + 1 - 3a) (x2 + 2x + 1 +3ax + 3a + 9a2)
