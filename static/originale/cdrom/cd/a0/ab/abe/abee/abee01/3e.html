    x2 + 2x + 1 - a2 =

i primi tre termini sono il quadrato di un binomio; il quarto termine e' anch'esso un quadrato

quindi posso scrivere

= (x + 1)2 - a2 =

Adesso posso considerarli due termini e precisamente due quadrati col segno meno in mezzo, quindi scompongo secondo la differenza di due quadrati

= [(x + 1) - a][(x + 1) + a] =

faccio cadere le parentesi tonde

= [x + 1 + a][x + 1 - a] =

per essere perfetto sostituisco le quadre con le tonde

= (x + 1 + a)(x + 1 - a)
