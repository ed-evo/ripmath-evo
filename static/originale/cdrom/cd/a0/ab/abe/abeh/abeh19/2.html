    (4x - 4y)(2x + 3y) - (x - y)2 - 4x2 + 4y2 =
Nota: quando hai un'espressione con una o piu' parentesi la parentesi non va mai calcolata ma devi invece fare in modo di raggruppare gli altri termini in modo da utilizzare la parentesi come un unico termine o parte di un unico termine. Le parentesi vanno calcolate solamemente se non puoi assolutamente fare nient'altro

Proviamo a raggrupparre
Nella prima parentesi del primo termine puoi mettere in evidenza 4;
il secondo termine e' un quadrato;
se fra il terzo ed il quarto termine raccogli il -4 ottieni una differenza di due quadrati

= 4(x - y)(2x + 3y) - (x - y)2 - 4(x2 - y2) =

scompongo la differenza di quadrati

= 4(x - y)(2x + 3y) - (x - y)2 - 4(x - y)(x + y) =

ora fra tutti i termini posso raccogliere (x - y);

= (x - y)[4(2x + 3y) - (x - y) - 4(x + y)] =

Non posso far altro che eseguire le operazioni dentro la quadra: calcolo e tolgo le parentesi tonde

= = (x - y)[8x + 12y - x + y - 4x - 4y] =

sommo i termini simili (e cambio le quadre con le tonde)

= (x - y)(3x + 9y) =

dentro la seconda parentesi posso raccogliere a fattor comune 3

= =(x - y)[3(x + 3y)] =

estraggo il 3 e lo scrivo davanti

= 3 (x - y)(x + 3y)
