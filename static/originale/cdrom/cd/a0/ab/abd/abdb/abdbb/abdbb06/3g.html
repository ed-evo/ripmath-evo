Eseguire la seguente divisione con metodo canonico

(a8 - b8) : (a3 + a2b + ab2 + b3) =

Ordino i polinomi secondo le potenze decrescenti di a

(a8 + 0a7 + 0a6 + 0a5 + 0a4 + 0a3 +0a2 + 0a - b8) : (a3 + a2b + ab2 + b3) =

scrivo a destra lo schema (al posto degli 0 metto 2 trattini trasversali)

Avendo quattro termin i al divisore considero, partendo da sinistra, i primi quattro posti a8   //   //   //

a8 // // // // // // // -b8 a3 +a2b +ab2 +b3
-a8 -a7b -a6b2 -a5b3 a5 -a4b
// -a7b -a6b2 -a5b3 //
-     -     -     -    
divido a8 per il primo termine del divisore a3 e scrivo il risultato a5 nella riga sotto il divisore

moltiplico il risultato trovato a5 per il divisore
a3 + a2b + ab2 + b3, ottengo a8 + a7b + a6b2 + a5b3 ,
cambio di segno e scrivo -a8 - a7b - a6b2 - a5b3 nella riga sotto a8 in modo da incolonnare i termini simili
(anche se non si vedono ricorda che negli spazi con trattini sono sottointesi termini del tipo 0an)

verticalmente faccio la somma algebrica, ottengo
- a7b - a6b2 - a5b3

abbasso sulla riga del risultato trovato i termini in alto // in modo da avere ancora quattro posti

divido - a7b per il primo termine del divisore a3 e scrivo il risultato - a4b nella riga sotto il divisore

 ora moltiplica il risultato trovato - a4b per il divisore a3 + a2b + ab2 + b3, e quello che ottieni scrivilo cambiato di segno, sotto -a7b - a6b2 - a5b3 (nelle caselle rosse) in modo da incolonnare i termini simili
