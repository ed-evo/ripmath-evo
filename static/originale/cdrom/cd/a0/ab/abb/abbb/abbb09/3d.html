Calcolare il seguente prodotto fra polinomi

(x2 - x + 1)(x2 + x - 1)=

Moltiplico ogni termine del primo (trinomio) per ogni termine del secondo (trinomio): avro' 9 termini

= x2·x2 + x2·x + x2·(-1) -x·x2 - x·x - x·(-1) + 1·x2 + 1·x + 1·(-1) =

= x4 + x3 - x2 -x3 - x2 + x + x2 + x - 1 =

Ora contrassegno sotto con simboli uguali i termini simili:
= x4 + x3 - x2 - x3 - x2 + x + x2 + x - 1 =
