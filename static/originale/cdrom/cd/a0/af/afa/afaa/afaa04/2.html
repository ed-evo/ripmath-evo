sviluppo

Dire, senza risolverlo, se il sistema e' possibile, impossibile oppure indeterminato

(x + 1)2 + (y + 1)2 - (x2 + y2) = 8
x + y = 2


prima devo ridurre il sistema a forma normale eseguendo le operazioni indicate

sviluppo i quadrati e tolgo le parentesi nella prima equazione (la seconda e' a posto)

x2 + 2x + 1 + y2 + 2y + 1 - x2 - y2 = 8
x + y = 2


sommo i termini simili ed ottengo

2x + 2y + 2 = 8
x + y = 2


nella prima equazione porto il termine senza la x dopo l'uguale

2x + 2y = 8 - 2
x + y = 2


sommo dopo l'uguale

2x + 2y = 6
x + y = 2
applico il secondo principio di equivalenza delle equazioni per semplificare la prima equazione (divido per 2)

x + y = 3
x + y = 2


Il sistema e' ora ridotto a forma normale

Le equazioni non sono linearmente dipendenti, cioe' non posso renderle uguali moltiplicando per un opportuno numero

Siccome la somma di termini uguali non puo' dare risultati diversi devo dire che

il sistema e' impossibile e non ammette soluzioni
