Calcolare le soluzioni del seguente sistema

x

2y 		 =  1
x + 2y  =  8


Devo ridurre il sistema a forma normale eseguendo tutte le operazioni
Avendo la y al denominatore devo porre la condizione di realta' delle radici


condizione di realta'
C.R.     2y ≠ 0   →   y ≠ 0

adesso moltiplico la prima in croce

x  =  2y
x + 2y  =  8


sostituisco subito nella seconda il valore della x trovato nella prima
al posto della prima metto una linea

2y + 2y  = 8


sommo i termini simili

4y  =  8


sotto divido per 4 (secondo principio); sopra riscrivo l'equazione al posto della linea

x  =  2y
y  =  2


sostituisco ad y sopra il valore trovato nella seconda

x  =  2·2 = 4
y  =  2


soluzione
x  =  4
y  =  2
