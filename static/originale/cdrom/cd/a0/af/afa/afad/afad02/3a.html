apprendimento

Calcolare le soluzioni del seguente sistema

ax + by  =  0
x + y  =  b - a


Il sistema e' gia' ridotto a forma normale
uso il metodo di sostituzione
ricavo x dalla seconda e sostituisco il valore nella prima

a(b - a - y) + by  =  0
x  =  b - a - y


adesso risolvi la prima equazione fino a trovare il valore di y;
nei vari passaggi, al posto dell seconda metti una linea; nell'ultimo passaggio riscrivi tutta la seconda
esegui e vai avanti
