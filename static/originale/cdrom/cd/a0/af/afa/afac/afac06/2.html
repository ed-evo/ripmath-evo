sviluppo

Calcolare le soluzioni del seguente sistema

x - 2y  =  3
3x + y2  =  (3 + y)2


Devo ridurre il sistema a forma normale eseguendo tutte le operazioni
Sopra e' a posto; sotto sviluppo il quadrato di binomio

x - 2y  =  3
3x + y2  =  9 + 6y + y2


sotto porto i termini con le incognite prima dell'uguale cambiandoli di segno (primo principio di equivalenza)

x - 2y  =  3
3x + y2 - 6y - y2  =  9


sommo i termini simili

x - 2y  =  3
3x - 6y  =  9


semplifico la seconda equazione per 3 (secondo principio di equivalenza)

x - 2y  =  3
x - 2y  =  3


Essendo le due equazioni identiche il sistema e' indeterminato
