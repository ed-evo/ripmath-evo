Calcolare le soluzioni del seguente sistema

2(x - y) + 3y - 2(x + 1) =  y
4x + y  =  0


Devo ridurre il sistema a forma normale eseguendo tutte le operazioni
Sotto e' a posto; sopra eseguo i prodotti

2x - 2y + 3y - 2x - 2  =  y
4x + y  =  0


sopra porto il termine -2 dopo l'uguale ed il termine +y prima dell'uguale cambiandoli di segno

2x - 2y + 3y - 2x - y  =  2
4x + y  =  0


sommo i termini simili

0  =  2
4x + y  =  0
