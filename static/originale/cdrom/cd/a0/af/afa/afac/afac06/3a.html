apprendimento

Calcolare le soluzioni del seguente sistema

x - 2y  =  3
3x + y2  =  (3 + y)2


Devo ridurre il sistema a forma normale eseguendo tutte le operazioni
Sopra e' a posto; sotto sviluppo il quadrato di binomio

x - 2y  =  3
3x + y2  =  9 + 6y + y2


sotto porta i termini con le incognite prima dell'uguale cambiandoli di segno (primo principio di equivalenza)
esegui e vai avanti
