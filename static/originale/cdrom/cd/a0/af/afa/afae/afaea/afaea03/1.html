Risolvere il seguente problema

Trovare due numeri che hanno sia come somma che come quoziente 3

primo numero = x
secondo numero = y
 "hanno come somma 3" si scrive
x + y = 3

hanno come quoziente 3 si scrive
x/y = 3                           c.r. y≠0
x = 3y

Faccio il sistema
x + y = 3
x = 3y

risolvo con il metodo di sostituzione
3y + y = 3
x = 3y

4y = 3
x = 3y

y = 3/4
x = 3·3/4 = 9/4


    x = 9/4
    y=3/4


Risposta: il primo numero e' 9/4, il secondo e' 3/4
