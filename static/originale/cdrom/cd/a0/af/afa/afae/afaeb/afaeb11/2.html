Risolvere il seguente problema

In un trapezio isoscele la differenza fra la base maggiore ed uno dei lati obliqui e' 5/4 della base minore. Sapendo che la differenza fra il doppio della base maggiore ed il triplo della base minore e' il doppio della base minore stessa e che il lato obliquo supera di 5a la base minore, trovare l'area del trapezio

A destra traccio la figura e scrivo l'ipotesi(hp) e la tesi(th)
Per scrivere l'ipotesi scorro il testo e lo riscrivo in linguaggio geometrico:
Trapezio isoscele AB=CD
"la differenza fra la base maggiore ed uno dei lati obliqui e' 5/4 della base minore" scrivo BC-AB=5/4AD
"la differenza fra il doppio della base maggiore ed il triplo della base minore e' il doppio della base minore stessa " scrivo 2BC-3AD=2AD
"il lato obliquo supera di 5a la base minore" scrivo AB=5a+AD
 La tesi dice che devo trovare l'area, per trovare il'area ho bisogno delle due basi e dell'altezza AH ; trovo le basi con le relazioni che ho, poi, applicando il teorema di Pitagora al triangolo ABH, trovero' il raggio AH

Qui mi servirebbero 3 incognite, uso l'ultima relazione per sviluppare il problema con due incognite: se indico con x la base maggiore e con y la base minore per l'ultima relazione il lato obliquo sara' y+5a

BC = x
AD = y
AB = y + 5a

scrivo le relazioni in linguaggio algebrico

"la differenza fra la base maggiore ed uno dei lati obliqui e' 5/4 della base minore" si scrive
x - (y+5a) = 5/4 y
x - y - 5a = 5/4 y
4x - 4y - 20a = 5y
4x - 9y = 20a

"la differenza fra il doppio della base maggiore ed il triplo della base minore e' il doppio della base minore stessa " si scrive
2x - 3y = 2y
2x - 5y = 0

Faccio il sistema
    4x - 9y = 20a
    2x - 5y = 0

risolvo con il metodo di metodo di addizione, moltiplico la seconda equazione per -2 e sommo in verticale
    4x - 9y = 20a
    -4x + 10y = 0

ottengo     y = 20a

sostituisco nella seconda equazione

-4x + 10 · 20a = 0
4x = 200a
x = 50a
    x = 50a
    y = 20a

quindi
BC = 50a
AD = 20a
AB = y + 5 = 25a
 ora posso trovare l'altezza AH
trovo prima BH, osservando che, essendo il trapezio isoscele, ognuno dei due segmenti BH e KC e' uguale alla differenza delle basi fratto 2
BH = (BC-AD)/2 = (50a-20a)/2 = 15a

applico il teorema di Pitagora al triangolo rettangolo ABH per trovare AH
AH2 = AB2 - BH2 = (25a)2 - (15a)2= 625a2 - 225a2 =400a2
AH = √400a2 = 20a

 Area = (BC+AD)·AH /2 = (50a + 20a)·20a /2 =10000a2

l'area vale 10000a2
