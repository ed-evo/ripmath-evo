Risolvere il seguente problema

In un triangolo isoscele la somma fra la base ed il lato obliquo aumentata di 6a equivale alla differenza fra la base ed il lato obliquo moltiplicata per 8, mentre il perimetro vale 60a. Calcolare l'area del triangolo

BC=x
AC = y
"la somma fra la base ed il lato obliquo aumentata di 6a equivale alla differenza fra la base ed il lato obliquo moltiplicata per 8" si scrive
x + y + 6a = 8(x - y)
7x - 9y = 6a

"il perimetro vale 60a" si scrive
x + 2y = 60a

Faccio il sistema
    7x - 9y = 6a
    x + 2y = 60a

    7(60a - 2y) - 9y = 6a
    x = 60a - 2y

    420a - 14y - 9y = 6a
    x = 60a - 2y

    23y = 414a
    x = 60a - 2y

    y = 18a
    x = 60a - 2·18a = 60a - 36a = 24a

    x = 24a
    y = 18a

AB = 24a
BC = 18a
BH = BC/2 = 9a

applico il teorema di Pitagora al triangolo rettangolo ABH per trovare AH
AO2 = AH2 + OH2 = (24a)2 -(9a)2= 576a2 - 81a2 =495a2
AH = √495 a2 = 3a√55

 Area = BC·AH /2 = 18a ·3a√55 /2 = 54a2√55 /2 = 27a2√55

L'area vale 27a2√55
