Calcolare le soluzioni del seguente sistema con il metodo di addizione

x + y = a + b
x - y = a - b


devo rendere due termini verticali contenenti l'incognita uguali e di segno contrario, cosi', sommandoli, spariscono:
moltiplico la seconda equazione per -1

x + y = a + b
- x + y = - a + b


sommo in verticale

     x   + y   =   a + b   +
    -x   + y   = - a + b
   
        //     2y    =   2b


adesso risolvo l'equazione trovata

    2y = 2b

divido tutto per 2 per trovare la y (secondo principio di equivalenza delle equazioni)

    y = b

nel sistema iniziale, avendo le y coefficienti uguali ed opposti posso sommare direttamente
sommo in verticale

    x   + y   =  a + b   +
    x   - y    =   a - b
   
      2x    //     =   2a


Hai trovato l'equazione

    2x = 2a

adesso risolvila
