Calcolare le soluzioni del seguente sistema con il metodo di addizione

2x - y = 6a
x - 2y = 0


devo rendere due termini verticali contenenti l'incognita uguali e di segno contrario, cosi', sommandoli, spariscono:
per redere uguali i coefficienti delle x moltiplico sotto per -2

2x - y = 6a
-2x + 4y = 0


sommo in verticale

     2x   - y   =   6a   +
    -2x + 4y   =   0
   
        //     3y    =   6a


adesso risolvo l'equazione trovata

    3y = 6a

divido tutto per 3 per trovare la y (secondo principio di equivalenza delle equazioni)

    y = 2a

nel sistema iniziale, per trovare la y moltiplico la prima equazione per -2
sommo in verticale

    -4x   + 2y   =   -12a   +
     x     - 2y     =   0
   
     -3x      //      =  -12a


    -3x = -12a

divido tutto per -3 (secondo principio)

    x = 4a

riporto i risultati nella graffa

    x = 4a
    y = 2a
