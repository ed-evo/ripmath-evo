Calcolare le soluzioni del seguente sistema con il metodo di addizione

    (a - b)x - (a + b)y = 2a2
    (a + b)x - (a - b)y = 2ab


moltiplico la prima equazione per (a+b) e la seconda per -(a-b)

    (a - b)(a + b)x - (a + b)2y = 2a2(a + b)
    -(a + b)(a - b)x + (a - b)2y = -2ab(a - b)


     (a - b)(a + b)x   - (a + b)2y  =   2a2(a + b)   +
    -(a + b)(a - b)x   + (a - b)2y  =   -2ab(a - b)
   
              //        -(a+b)2y+(a-b)2y = 2a2(a+b)-2ab(a-b)

   -(a + b)2y + (a - b)2y = 2a2( a + b) - 2ab( a - b)

   -a2y - 2aby - b2y + a2y - 2aby + b2y = 2a3 + 2a2b -2a2b + 2ab2

    - 2aby - 2aby = 2a3 + 2ab2

    - 4aby = 2a(a2 + b2)

    4aby = -2a(a2 + b2)

se ab≠0 posso applicare il secondo principio dividendo tutto per 4aby

       y = -2a(a2 + b2)

4ab

considero i 3 casi

  • se a=0 e b=0 sostituisco ed ottengo
        2·0·0·x = -2·0(02 + 02)
        0x = 0 e l'equazione e' indeterminata

  • se a=0 e b≠0 sostituisco ed ottengo
        4·0·by = -2·0(02 + b2)
        0y = 0 e l'equazione e' indeterminata

  • se a≠0 e b=0 sostituisco ed ottengo
        4a·0·y = -2a(a2 + 02)
        0y = -4a3 ed essendo a≠0 l'equazione e' impossibile

     (a - b)2x   - (a + b)(a - b)y  =   2a2(a - b)   +
