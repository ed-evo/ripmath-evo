Risolvere il seguente problema

La somma delle eta' di Aldo e Giovanni supera il secolo di 6 anni. L'anno prossimo l'eta' di Aldo sara' il doppio dell'eta' di Giovanni. Quanti anni hanno Aldo e Giovanni?

    eta' di Aldo = x

    eta' di Giovanni = 106 - x

    x + 1 = 2(106 - x + 1)

    x + 1 = 212 - 2x + 2

    x + 2x = 212 + 2 - 1

    3x = 213

    x = 71

    eta' di Aldo = x = 71

    eta' di Giovanni = 106 - x = 106 - 71 = 35
