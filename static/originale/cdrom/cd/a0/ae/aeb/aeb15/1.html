Risolvere il seguente problema

Si utilizza una prima volta la meta' dell'acqua contenuta in un serbatoio piu' 30 litri, successivamente si usano i 2/3 dell'acqua rimasta piu' 50 litri. Sapendo che nel serbatoio restano 40 litri d'acqua quanti litri conteneva inizialmente il serbatoio?

    litri che conteneva inizialmente il serbatoio = x

    acqua utilizzata la prima volta = 1/2 x + 30

    acqua restata dopo il primo utilizzo = x -(1/2 x + 30) = 1/2 x - 30

    acqua utilizzata la seconda volta = 2/3(1/2 x - 30) + 50 = 1/3 x -20 + 50 = 1/3 x + 30

    3x + 180 + 2x + 180 + 240 = 6x

    3x + 2x - 6x = - 180 - 180 - 240

    -x = - 600

    x = 600

    litri che conteneva inizialmente il serbatoio = x = 600
