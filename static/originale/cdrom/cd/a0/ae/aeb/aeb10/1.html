Risolvere il seguente problema

L'eta' di un padre supera di 18 anni la somma delle eta' dei suoi due figli e l'eta' del figlio maggiore e' i 5/3 dell'eta' del fratello. Determinare le loro eta' sapendo che fra due anni l'eta' del padre sara' 4 volte l'eta' del figlio minore

    eta' figlio minore = x

    eta' figlio maggiore = 5/3 x

    eta' del padre = 18 + x + 5/3 x

    eta' del padre fra due anni = 18 + x + 5/3 x + 2 = 20 + x + 5/3 x

    eta' figlio minore fra due anni = x + 2

    20 + x + 5

3 		x = 4(x + 2)


    20 + x + 5

3 		x = 4x + 8


    60 + 3x + 5x

3 		= 12x + 24

    60 + 3x + 5x = 12x + 24

    3x + 5x - 12x = 24 - 60

    - 4x = - 36

    x = 9

    eta' figlio minore = x = 9

    eta' figlio maggiore = 5/3 x = 5/3 · 9 = 15
