Risolvere il seguente problema

Calcolare le misure delle basi di un trapezio sapendo che la base maggiore supera la minore di 10 cm, l'altezza e' di 20 cm e l'area di 200 cm2

ipotesi: la base maggiore supera la minore di 10 cm
l'altezza e' di 20 cm
l'area e' di 400 cm2 (somma delle basi per altezza diviso 2)
tesi: trovare le misure delle basi

lunghezza base minore = AD = x

lunghezza base maggiore = BC = x + 10 cm

misura dell'altezza = AH = 20cm

conosco il valore dell'area

    Area = (AD + BC)· AH

2 		= 200 cm2

sostituisco

    (x + x + 10)·20

2 		= 200

    (2x + 10)·20

2 		= 200

    40x + 200

2 		= 200

    40x + 200

2 		= 400

2
   40x + 200 = 400

    40x = 400 - 200

    40x = 200

    x = 5

lunghezza base minore = AD = x = 5 cm

lunghezza base maggiore = BC = x + 10 cm = 15 cm
