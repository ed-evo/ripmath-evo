       dire se il seguente insieme e' ordinato, e' bene ordinato oppure no

    A = { x ∈ ℜ / x(k) = 2k , ∀ k∈N }

L'insieme e' formato dai punti della retta reale corrispondente ai numeri interi pari

A = { x ∈ ℜ / x = 2, 4, 6, 8, 10, 12,..... }


l'insieme e' ordinato con la relazione "minore di", essendo ogni numero dell'insieme nella retta ℜ minore di ogni numero che si trovi alla sua sinistra

L'insieme e' bene ordinato perche' comunque io prenda un suo sottoinsieme proprio questo avra' un primo elemento che corrispondera' all'elemento che si trova piu' a sinistra nella retta reale
Essendo N un insieme bene ordinato qualunque insieme che possa essere messo in corrispondenza biunivoca con N e', anche lui, bene ordinato
