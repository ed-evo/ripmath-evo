Data la seguente funzione determinatene, se possibile, la funzione inversa indicandone anche le eventuali restrizioni nel dominio

    y = 3 |x|

La funzione e' definita su tutto ℜ

Essendovi il modulo, per eliminarlo, spezziamo la funzione nelle sue componenti seguendo la definizione di modulo

    y =  3x     se x ≥ 0
-3x     se x < 0
trovo quindi l'inversa per le due funzioni:

la prima y = 3x     in D = {x ∈ ℜ / x ≤ 0}
la seconda y = -3x     in D = {x ∈ ℜ / x> 0}

considero la prima
y = 3x
la condizione x ≥ 0 implica y ≥ 0
Infatti se x=0 allora y=0 e se x e' positivo lo e' anche y

per trovarne l'inversa scambio tra loro x ed y

x = 3y
ricavo la y ed ottengo
    y =   1

considero la seconda
y = -3x
la condizione x < 0 implica y < 0
Infatti se x e' negativo lo e' anche y

per trovarne l'inversa scambio tra loro x ed y

x = -3y
ricavo la y ed ottengo
    y = -  1

    y = 1
