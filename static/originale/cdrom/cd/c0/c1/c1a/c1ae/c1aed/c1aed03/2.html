Dite se la seguente funzione e' pari, dispari, periodica motivando tale affermazione

    y = x2 - x + 2

Non e' una funzione pari perche' se cambio di segno l'incognita la funzione non mantiene lo stesso segno
infatti cambiando x con -x ottengo

f(-x) = (-x)2 -(-x) + 2 = x2 + x + 2 ≠f(x)

Non e' una funzione dispari perche' se cambio di segno l'incognita la funzione non cambia tutta di segno
infatti cambiando x con -x ottengo

f(-x) = (-x)2 -(-x) + 2 = x2 + x + 2 ≠-f(x)
