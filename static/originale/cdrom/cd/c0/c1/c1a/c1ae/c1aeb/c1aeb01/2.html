Seguendo la definizione di Dirichlet dite se le seguenti espressioni rappresentano o meno una funzione reale di una variabile reale evidenziando quale e' l'insieme dominio e quale l'insieme codominio

    y = x3 + 5x2 + 1


Si tratta di una funzione perche'ad ogni valore di x corrisponde un valore di y
basta sostituire ad x un qualunque valore appartenente ad ℜ per ottenere un ben definito valore per y in ℜ
esempio per x=0 ottengo y=03 + 5·02 + 1= 1

Il dominio e' tutto ℜ     D = ]-∞ +∞[     perche' posso sostituire ad x qualunque suo valore
Il codominio e' tutto ℜ     C = ]-∞ +∞[     perche' posso ottenere per y qualunque suo valore
