Seguendo la definizione di Dirichlet dite se le seguenti espressioni rappresentano o meno una funzione reale di una variabile reale evidenziando quale e' l'insieme dominio e quale l'insieme codominio

0 per x = 0

Quindi, essendo l'espressione un tutto unico, non si tratta di una funzione
