    considerato il seguente intervallo dire se e' aperto o chiuso

    I = { x ∈ ℜ / 5 ≤ x }


E' un intervallo "infinito"; meglio dire illimitato a destra, formato da tutti i numeri reali maggiori di 5; essendo il punto 5 compreso in I diremo che e' chiuso a sinistra
Illimitato a destra significa che non posso trovare nessun valore che sia superiore a tutti i valori dei punti dell'intervallo



I = { x ∈ ℜ / 5 ≤ x } = [5,+∞[
