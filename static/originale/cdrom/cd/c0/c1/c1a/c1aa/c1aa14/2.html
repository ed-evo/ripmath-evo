       indicare in ℜ sia un intorno chiuso sia un intorno aperto di -∞ e darne una rappresentazione


Per indicare un intorno di -∞ consideriamo un numero N
l'insieme dei punti minori di N sara' un intorno aperto di -∞
 I ={ x ∈ ℜ / x <N } = ]-∞; N [

l'insieme dei punti minori od uguali ad N sara' un intorno chiuso di -∞
 I ={ x ∈ ℜ / x ≤ N } = ]-∞; N]
