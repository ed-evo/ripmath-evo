    indicare in ℜ un intorno completo di ∞
   darne una rappresentazione


Per indicare un intorno di ∞ consideriamo un numero M ed un numero N tali che N < M
un intorno aperto di ∞ sara' l'unione dell'insieme dei punti minori di N e dell'insieme dei punti maggiori di M
 I ={ x ∈ ℜ / x < N ; x > M} = ]-∞; N [ ∪ ]M ; +∞ [

un intorno chiuso di ∞ sara' l'unione dell'insieme dei punti minori od uguali ad N e dell'insieme dei punti maggiori o uguali di M
 I ={ x ∈ ℜ / x ≤ N ; x ≥ M} = ]-∞; N ] ∪ [M ; +∞ [
