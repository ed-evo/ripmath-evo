considerato il seguente intervallo dire se e' aperto o chiuso

       I = { x∈ℜ / cos π < x < 3√5 }


Essendovi solo il segno di minore gli estremi non sono compresi nell'insieme I

quindi l'insieme I, non comprendendo i suoi estremi, e' aperto

I = { x ∈ ℜ / cos π ≤ x ≤ 3√5 } = ]-1, 3√5[
Da notare che i punti sono individuati comunque anche se non vengono indicati nel modo classico
vale cos π = -1
