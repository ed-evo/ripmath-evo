Dire se il seguente insieme e' infinito giustificando tale affermazione

    I = { x ∈C / x(k) = ik , ∀ k∈N }


    Devo trovare nell'insieme dei numeri complessi i punti che obbediscono alla relazione x(k) = ik per ogni k∈N

per trovarli sostituisco a k i valori della successione dei numeri naturali N e trovo i punti corrispondenti

Per k = 1     → x(1) = i1 = i
Per k = 2     → x(2) = i2 =- 1
Per k = 3     → x(3) = 13 = - i
Per k = 4     → x(4) = i4 = + 1
Per k = 5     → x(5) = i5 = i
Per k = 6     → x(6) = i6 = - 1
Per k = 7     → x(7) = i7 = - i
Per k = 8     → x(8) = i8 = + 1
Per k = 9     → x(9) = i9 = i
