Dominio o campo di esistenza di una funzione


Il dominio o campo di esistenza e' limitato solamente quando abbiamo una funzione fratta, una funzione irrazionale oppure una funzione logaritmica: negli altri casi il dominio e' tutto ℜ
Quindi distinguiamo i vari casi

  • funzioni fratte
  • funzioni irrazionali
  • funzioni logaritmiche
  • esercizi di riepilogo
