La mia disequazione è equivalente ai 333 sistemi:

I $$ \begin{cases} -x - 4 - (-x + 2) > -x + 8 \ x < -4 \end

IIII II

\begin{cases} x + 4 - (-x + 2) > -x + 8 \ -4 \le x < 2 \end

IIIIII III

\begin{cases} x + 4 - (x - 2) > -x + 8 \ x \ge 2 \end

> **Nota:** Da notare che, se usi il sistema, non c'è più bisogno di fare riferimento all'intervallo di validità perché esso è inglobato nel sistema stesso, quindi otterrai automaticamente i risultati negli intervalli validi. ### [Risolvo il primo sistema]{.text-red-darken-1}

\begin{cases} -x - 4 - (-x + 2) > -x + 8 \ x < -4 \end

\begin{cases} -x - 4 + x - 2 > -x + 8 \ x < -4 \end

\begin{cases} -6 > -x + 8 \ x < -4 \end

\begin{cases} x > 8 + 6 \ x < -4 \end

\begin{cases} x > 14 \ x < -4 \end

Il sistema non ammette soluzione (devi considerare dove sono valide entrambe). ### [Risolvo il secondo sistema]{.text-green}

\begin{cases} x + 4 - (-x + 2) > -x + 8 \ -4 \le x < 2 \end

\begin{cases} x + 4 + x - 2 > -x + 8 \ -4 \le x < 2 \end

\begin{cases} 2x + 2 > -x + 8 \ -4 \le x < 2 \end

\begin{cases} 2x + x > 8 - 2 \ -4 \le x < 2 \end

\begin{cases} 3x > 6 \ -4 \le x < 2 \end

\begin{cases} x > 2 \ -4 \le x < 2 \end

Il sistema non ammette soluzione (devi considerare dove sono valide entrambe e $2$ non appartiene né alla prima, né alla seconda disequazione). ### [Risolvo il terzo sistema]{.text-blue}

\begin{cases} x + 4 - (x - 2) > -x + 8 \ x \ge 2 \end

\begin{cases} x + 4 - x + 2 > -x + 8 \ x \ge 2 \end

\begin{cases} 6 > -x + 8 \ x \ge 2 \end

\begin{cases} x > -6 + 8 \ x \ge 2 \end

\begin{cases} x > 2 \ x \ge 2 \end

Il sistema ammette soluzione $x > 2$ (devi considerare dove sono valide entrambe). Adesso metto assieme i risultati dei tre sistemi e trovo la soluzione. ## Soluzione $x > 2$ cioè $\forall x \in \mathbb{R} / x \in ]2, +\infty[$ > **Nota:** Il simbolo $/$ significa "tale che". Si legge: per ogni numero reale $x$ tale che $x$ appartenga all'intervallo aperto da $2$ a più infinito: aperto significa che $2$ non è una soluzione, cioè non è compreso nell'intervallo delle soluzioni.
