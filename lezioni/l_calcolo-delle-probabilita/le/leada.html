Data la variabile aleatoria

Xi\textcolor{red}{X_i}Xi​X1\textcolor{red}{X_1}X1​X2\textcolor{red}{X_2}X2​X3\textcolor{red}{X_3}X3​…\dots…Xn\textcolor{red}{X_n}Xn​
f\textcolor{red}{f}fp1\textcolor{red}{p_1}p1​p2\textcolor{red}{p_2}p2​p3\textcolor{red}{p_3}p3​…\dots…pn\textcolor{red}{p_n}pn​

M(X)\textcolor{red}{M(X)}M(X) sarà una media rappresentativa se i valori della media si scostano poco da quelli della variabile, cioè se sono abbastanza piccoli gli scarti (differenze fra la media ed i valori):

M(X)−X1,M(X)−X2,M(X)−X3,…,M(X)−Xn\textcolor{red}{M(X)-X_1, M(X)-X_2, M(X)-X_3, \dots, M(X)-X_n}M(X)−X1​,M(X)−X2​,M(X)−X3​,…,M(X)−Xn​

Però usare una tabella è poco pratico: più utile è concentrare i risultati in un unico numero; il calcolo più intuitivo sembra essere di farne il valore medio.

Valore medio=[M(X)−X1]p1+[M(X)−X2]p2+[M(X)−X3]p3+⋯+[M(X)−Xn]pn\textcolor{red}{\text{Valore medio} = [M(X)-X_1] p_1 + [M(X)-X_2] p_2 + [M(X)-X_3] p_3 + \dots + [M(X)-X_n] p_n}Valore medio=[M(X)−X1​]p1​+[M(X)−X2​]p2​+[M(X)−X3​]p3​+⋯+[M(X)−Xn​]pn​

Eseguo le moltiplicazioni:

=M(X)p1−X1p1+M(X)p2−X2p2+M(X)p3−X3p3+⋯+M(X)pn−Xnpn\textcolor{red}{= M(X)p_1 - X_1p_1 + M(X)p_2 - X_2p_2 + M(X)p_3 - X_3p_3 + \dots + M(X)p_n - X_np_n} =M(X)p1​−X1​p1​+M(X)p2​−X2​p2​+M(X)p3​−X3​p3​+⋯+M(X)pn​−Xn​pn​

Raggruppo i termini positivi e negativi:

=M(X)p1+M(X)p2+M(X)p3+⋯+M(X)pn−X1p1−X2p2−X3p3⋯−Xnpn\textcolor{red}{= M(X)p_1 + M(X)p_2 + M(X)p_3 + \dots + M(X)p_n - X_1p_1 - X_2p_2 - X_3p_3 \dots - X_np_n} =M(X)p1​+M(X)p2​+M(X)p3​+⋯+M(X)pn​−X1​p1​−X2​p2​−X3​p3​⋯−Xn​pn​

Tra quelli positivi raccolgo M(X)M(X)M(X), fra quelli negativi raccolgo il segno meno:

=M(X)[p1+p2+p3+⋯+pn]−(X1p1+X2p2+X3p3⋯+Xnpn)\textcolor{red}{= M(X)[p_1 + p_2 + p_3 + \dots + p_n] - (X_1p_1 + X_2p_2 + X_3p_3 \dots + X_np_n)} =M(X)[p1​+p2​+p3​+⋯+pn​]−(X1​p1​+X2​p2​+X3​p3​⋯+Xn​pn​)

Ora so che la somma delle probabilità vale 111 e che la somma dopo il segno meno è il valore medio M(X)M(X)M(X), quindi ottengo:

=M(X)−M(X)=0\textcolor{red}{= M(X) - M(X) = 0} =M(X)−M(X)=0

Quindi la scelta della media degli scarti non va bene.

Allora prendiamo i quadrati degli scarti, perché essendo tutti positivi, facendone la somma non otterremo un valore nullo. Prendo i quadrati degli scarti:

[M(X)−X1]2,[M(X)−X2]2,[M(X)−X3]2,…,[M(X)−Xn]2\textcolor{red}{[M(X)-X_1]^2, [M(X)-X_2]^2, [M(X)-X_3]^2, \dots, [M(X)-X_n]^2}[M(X)−X1​]2,[M(X)−X2​]2,[M(X)−X3​]2,…,[M(X)−Xn​]2

La media sarà:

σ2(X)=[M(X)−X1]2p1+[M(X)−X2]2p2+[M(X)−X3]2p3+⋯+[M(X)−Xn]2pn\textcolor{red}{\sigma^2(X) = [M(X)-X_1]^2 p_1 + [M(X)-X_2]^2 p_2 + [M(X)-X_3]^2 p_3 + \dots + [M(X)-X_n]^2 p_n} σ2(X)=[M(X)−X1​]2p1​+[M(X)−X2​]2p2​+[M(X)−X3​]2p3​+⋯+[M(X)−Xn​]2pn​

Di solito si scrive nella forma più compatta:

σ2(X)=∑k=1n(M(X)−Xk)2pk\textcolor{red}{\sigma^2(X) = \sum_{k=1}^{n} (M(X) - X_k)^2 p_k} σ2(X)=k=1∑n​(M(X)−Xk​)2pk​
