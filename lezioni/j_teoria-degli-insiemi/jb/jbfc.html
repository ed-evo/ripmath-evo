Proprietà delle operazioni unione ed intersezione ​

Vediamo in questa pagina le principali proprietà dell'unione e dell'intersezione

È possibile dimostrarle abbastanza facilmente utilizzando i diagrammi di Eulero-Venn (da fare in futuro).

Proprietà commutativa ​

per l'unione:

A∪B=B∪A\textcolor{red}{A \cup B = B \cup A} A∪B=B∪A

per l'intersezione:

A∩B=B∩A\textcolor{red}{A \cap B = B \cap A} A∩B=B∩A

Proprietà associativa ​

per l'unione:

(A∪B)∪C=A∪(B∪C)\textcolor{red}{(A \cup B) \cup C = A \cup (B \cup C)} (A∪B)∪C=A∪(B∪C)

per l'intersezione:

(A∩B)∩C=A∩(B∩C)\textcolor{red}{(A \cap B) \cap C = A \cap (B \cap C)} (A∩B)∩C=A∩(B∩C)

Proprietà di idempotenza ​

per l'unione:

A∪A=A\textcolor{red}{A \cup A = A} A∪A=A

per l'intersezione:

A∩A=A\textcolor{red}{A \cap A = A} A∩A=A

Proprietà dell'insieme vuoto ​

per l'unione:

A∪∅=∅∪A=A\textcolor{red}{A \cup \emptyset = \emptyset \cup A = A} A∪∅=∅∪A=A

per l'unione l'insieme vuoto è l'elemento neutro

per l'intersezione:

A∩∅=∅∩A=∅\textcolor{red}{A \cap \emptyset = \emptyset \cap A = \emptyset} A∩∅=∅∩A=∅

per l'intersezione l'insieme vuoto è l'elemento assorbente

Proprietà distributiva ​

dell'unione rispetto all'intersezione:

A∪(B∩C)=(A∪B)∩(A∪C)\textcolor{red}{A \cup (B \cap C) = (A \cup B) \cap (A \cup C)} A∪(B∩C)=(A∪B)∩(A∪C)

dell'intersezione rispetto all'unione:

A∩(B∪C)=(A∩B)∪(A∩C)\textcolor{red}{A \cap (B \cup C) = (A \cap B) \cup (A \cap C)} A∩(B∪C)=(A∩B)∪(A∩C)

Proprietà di assorbimento ​

A∪(A∩B)=A\textcolor{red}{A \cup (A \cap B) = A} A∪(A∩B)=A

A∩(A∪B)=A\textcolor{red}{A \cap (A \cup B) = A} A∩(A∪B)=A
