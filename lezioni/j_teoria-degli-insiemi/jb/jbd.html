Sottoinsiemi di un insieme ​

Definiamo sottoinsieme di un insieme dato un nuovo insieme che abbia come elementi degli elementi presenti nell'insieme di partenza: ad esempio dato

A={1,2,3,4}\textcolor{red}{A = \{ 1, 2, 3, 4 \}} A={1,2,3,4}

l'insieme

B={1,3}\textcolor{red}{B = \{ 1, 3 \}} B={1,3}

è un sottoinsieme dell'insieme AAA.

Dato un insieme definito mediante caratteristica per ottenerne un sottoinsieme basta aggiungere una proprietà: ad esempio se considero l'insieme dei numeri naturali minori di 555

A={x∈N:x<5}={1,2,3,4}\textcolor{red}{A = \{ x \in \mathbb{N} : x < 5 \} = \{ 1, 2, 3, 4 \}} A={x∈N:x<5}={1,2,3,4}

ed aggiungo l'insieme dei numeri naturali minori di 555 e non divisibili per 222 ottengo

B={x∈N:x<5;x non divisibile per 2}={1,3}\textcolor{red}{B = \{ x \in \mathbb{N} : x < 5; x \text{ non divisibile per } 2 \} = \{ 1, 3 \}} B={x∈N:x<5;x non divisibile per 2}={1,3}

Per indicare che BBB è sottoinsieme dell'insieme AAA useremo la notazione di inclusione

B⊂A\textcolor{red}{B \subset A} B⊂A

che si legge l'insieme BBB è contenuto nell'insieme AAA.

Per indicare che AAA ha come sottoinsieme BBB useremo invece la notazione

A⊃B\textcolor{red}{A \supset B} A⊃B

che si legge anche dicendo che AAA è un sovrainsieme di BBB o che l'insieme AAA contiene l'insieme BBB.

Però posso aggiungere una proprietà impossibile, come ad esempio l'insieme dei numeri naturali minori di 555 e divisibili per 777 ottengo un insieme senza elementi

B={x∈N:x<5;x eˋ divisibile per 7}=∅\textcolor{red}{B = \{ x \in \mathbb{N} : x < 5; x \text{ è divisibile per } 7 \} = \emptyset} B={x∈N:x<5;x eˋ divisibile per 7}=∅

∅\emptyset∅ sarà anche chiamato insieme vuoto ed è un sottoinsieme per ogni insieme: basta aggiungere alla caratteristica dell'insieme una proprietà impossibile.

Come abbiamo aggiunto una proprietà impossibile possiamo aggiungere una proprietà ovvia e quindi otterremo come sottoinsieme l'insieme di partenza: esempio se considero l'insieme dei numeri naturali minori di 555 e multipli di 111 ottengo lo stesso insieme di partenza

B={x∈N:x<5;x eˋ multiplo di 1}=A\textcolor{red}{B = \{ x \in \mathbb{N} : x < 5; x \text{ è multiplo di } 1 \} = A} B={x∈N:x<5;x eˋ multiplo di 1}=A

In questo caso per indicare che considero l'insieme di partenza come sottoinsieme di sé stesso lo chiamerò sottoinsieme improprio.

Siccome quando indicheremo genericamente un sottoinsieme di un insieme potrebbe trattarsi anche dell'insieme improprio allora per considerare anche questa possibilità indicheremo che BBB è sottoinsieme di AAA in questo modo

B⊆A\textcolor{red}{B \subseteq A} B⊆A

che si legge l'insieme BBB è contenuto od uguale all'insieme AAA.
