Definizione di fascio di circonferenze ​

Diremo che abbiamo un fascio di circonferenze se, all'interno dell'equazione, esiste un parametro che può variare senza alterare le condizioni per cui l'equazione è una circonferenza.

Equivale a dire che quando il parametro varia, non devono mutare le condizioni per cui l'equazione rappresenta una circonferenza (di solito basta controllare la prima condizione: i coefficienti di x2x^2x2 e y2y^2y2 devono essere uguali). Trovi le condizioni in fondo alla pagina Equazione generale della circonferenza.

Ad esempio: Consideriamo l'equazione

(1+k)x2+(1+k)y2+2kx−2y+k−1=0(1+k)x^2 + (1+k)y^2 + 2kx - 2y + k - 1 = 0 (1+k)x2+(1+k)y2+2kx−2y+k−1=0

Controllo che i coefficienti di x2x^2x2 e y2y^2y2 siano uguali: (1+k)=(1+k)(1+k) = (1+k)(1+k)=(1+k).

Posso separare i termini contenenti kkk da quelli che non lo contengono ed ottengo

x2+y2−2y−1+k(x2+y2+2x+1)=0x^2 + y^2 - 2y - 1 + k(x^2 + y^2 + 2x + 1) = 0 x2+y2−2y−1+k(x2+y2+2x+1)=0

Si tratta della combinazione lineare di due circonferenze che, per ogni kkk, mi danno una circonferenza particolare;

se k=0k = 0k=0 ottengo la circonferenza

x2+y2−2y−1=0x^2 + y^2 - 2y - 1 = 0 x2+y2−2y−1=0

se k=∞k = \inftyk=∞ ottengo la circonferenza

x2+y2+2x+1=0x^2 + y^2 + 2x + 1 = 0 x2+y2+2x+1=0

Infatti se kkk tende a ∞\infty∞ allora il termine con kkk diventa preponderante ed il termine senza kkk diventa trascurabile e si annulla per il valore k=∞k = \inftyk=∞.

Viene allora spontaneo chiamare fascio di circonferenze l'insieme, al variare di kkk, rappresentato dal sistema

{(1+k)x2+(1+k)y2+x(a1+ka2)+y(b1+kb2)+c1+kc2=0x2+y2+a2x+b2y+c2=0\begin{cases} (1+k)x^2 + (1+k)y^2 + x(a_1 + ka_2) + y(b_1 + kb_2) + c_1 + kc_2 = 0 \\ x^2 + y^2 + a_2x + b_2y + c_2 = 0 \end{cases} {(1+k)x2+(1+k)y2+x(a1​+ka2​)+y(b1​+kb2​)+c1​+kc2​=0x2+y2+a2​x+b2​y+c2​=0​

od anche, per semplicità (ma con meno precisione) dall'equazione

(1+k)x2+(1+k)y2+x(a1+ka2)+y(b1+kb2)+c1+kc2=0(1+k)x^2 + (1+k)y^2 + x(a_1 + ka_2) + y(b_1 + kb_2) + c_1 + kc_2 = 0 (1+k)x2+(1+k)y2+x(a1​+ka2​)+y(b1​+kb2​)+c1​+kc2​=0

Le due circonferenze

x2+y2+a1x+b1y+c1=0x^2 + y^2 + a_1x + b_1y + c_1 = 0 x2+y2+a1​x+b1​y+c1​=0

x2+y2+a2x+b2y+c2=0x^2 + y^2 + a_2x + b_2y + c_2 = 0 x2+y2+a2​x+b2​y+c2​=0

Saranno chiamate circonferenze di base del fascio. Comunque lo stesso fascio si può ottenere considerando due qualunque circonferenze del fascio stesso come circonferenze di base; e, per ottenere una circonferenza del fascio, basterà sostituire a kkk un valore qualsiasi.
