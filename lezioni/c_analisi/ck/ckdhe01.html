x3−2x2−x+2=x^3 - 2x^2 - x + 2 = x3−2x2−x+2=

Scompongo:

=(x−1)(x+1)(x−2)= (x - 1)(x + 1)(x - 2) =(x−1)(x+1)(x−2)

Le tre radici (reali e distinte) del denominatore sono 111, −1-1−1, 222. Posso scrivere la frazione come somma delle tre frazioni:

−4x2−6x+7x3−2x2−x+2=Ax−1+Bx+1+Cx−2\frac{-4x^2 - 6x + 7}{x^3 - 2x^2 - x + 2} = \frac{A}{x - 1} + \frac{B}{x + 1} + \frac{C}{x - 2} x3−2x2−x+2−4x2−6x+7​=x−1A​+x+1B​+x−2C​

[Principio di identità dei polinomi:]{.text-purple} Due polinomi sono uguali se e solo se sono uguali tutti i termini dello stesso grado.

Quindi, essendo uguali i denominatori, perché anche i numeratori siano uguali deve essere:

A+B+C=−4A + B + C = -4 A+B+C=−4

−A−3B=−6-A - 3B = -6 −A−3B=−6

−2A+2B−C=7-2A + 2B - C = 7 −2A+2B−C=7

Pongo a sistema le tre equazioni per calcolare AAA, BBB e CCC:

{A+B+C=−4−A−3B=−6−2A+2B−C=7\begin{cases} A + B + C = -4 \\ -A - 3B = -6 \\ -2A + 2B - C = 7 \end{cases} ⎩⎨⎧​A+B+C=−4−A−3B=−6−2A+2B−C=7​
