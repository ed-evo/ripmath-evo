Ordinamento ​

È fondamentale in informatica considerare l'ordine in cui vengono date le informazioni: ho già detto che, semplificando, è come un lungo nastro di dati che scorre davanti ad un lettore, di conseguenza i dati dovranno essere ordinati per poter essere utilizzati.

Ripartiamo dal concetto di relazione d'ordine e vediamo il concetto di ordine parziale. Diremo che una relazione RRR su un insieme AAA è una relazione di ordine se è:

  • riflessiva
  • antisimmetrica
  • transitiva

Nota: E qui sarebbe meglio ripassare tutto il capitolo sulle relazioni.

Diremo che una relazione è di ordine totale su un insieme BBB se dati comunque due elementi aaa e bbb appartenenti a BBB vale sempre:

o aRb oppure bRa\text{o } aRb \text{ oppure } bRa o aRb oppure bRa

Cioè tutti gli elementi sono confrontabili fra loro secondo la relazione.

Esempio: l'insieme dei numeri naturali NNN con la relazione <<< è un insieme totalmente ordinato perché per due qualunque numeri naturali aaa e bbb posso sempre dire se vale a<ba < ba<b oppure b<ab < ab<a.

Se però esistono elementi di BBB fra loro non confrontabili secondo la relazione allora la relazione si dice di ordine parziale e l'insieme BBB si dice parzialmente ordinato.

Esempio: L'insieme degli esseri umani con la relazione "è antenato o identico di" è solo di ordine parziale perché due che siano fratelli non appartengono alla relazione.

Ripassiamo le relazioni nei particolari:

I. Riflessiva:

a≤a∀a∈Ba \le a \quad \forall a \in B a≤a∀a∈B

Si legge aaa è minore od uguale ad aaa per ogni elemento aaa appartenente a BBB. Cioè, in BBB ogni elemento è minore od uguale a se stesso (oppure, che è la stessa cosa, non è superiore a se stesso).

II. Antisimmetrica:

se a≤b e b≤a⇒a=b∀a,b∈B\text{se } a \le b \text{ e } b \le a \Rightarrow a = b \quad \forall a, b \in B se a≤b e b≤a⇒a=b∀a,b∈B

Si legge: se aaa è minore od uguale a bbb e bbb è minore od uguale ad aaa, allora aaa è uguale a bbb per ogni coppia di elementi a,ba, ba,b appartenenti a BBB. Cioè se aaa non è maggiore di bbb e bbb non è maggiore di aaa allora aaa e bbb sono uguali.

III. Transitiva:

a≤b,b≤c⇒a≤c∀a,b,c∈Ba \le b, b \le c \Rightarrow a \le c \quad \forall a, b, c \in B a≤b,b≤c⇒a≤c∀a,b,c∈B

Si legge se aaa è minore od uguale a bbb e bbb è minore od uguale a ccc allora aaa è minore od uguale a ccc per ogni terna di elementi a,b,ca, b, ca,b,c appartenenti a BBB.

Le algebre di Boole sono parzialmente ordinate a causa del teorema:

Sia BBB un'algebra di Boole, allora BBB è un insieme parzialmente ordinato con a≤ba \le ba≤b se e solo se a+b=ba + b = ba+b=b

Dimostrazione: Dimostriamolo "alla buona" con una dimostrazione non rigorosa, ma efficace, valida solo per l'algebra binaria di Boole (abbiamo solo gli elementi 000 ed 111). La condizione è necessaria e sufficiente (corrisponde a se e solo se).

Dimostrazione diretta: Ipotesi: supponiamo che nell'algebra binaria valga a+b=ba + b = ba+b=b. Tesi: devo dimostrare che vale a≤ba \le ba≤b.

L'ipotesi significa: 0+0=00 + 0 = 00+0=0, 0+1=10 + 1 = 10+1=1, 1+1=11 + 1 = 11+1=1. Cioè la somma equivale al secondo addendo se sono contemporaneamente nulli entrambi gli addendi oppure se il secondo addendo vale 111. Di conseguenza segue per ogni elemento aaa (che può essere 000 od 111):

  • se a=0a = 0a=0 e se b=0⇒0≤0b = 0 \Rightarrow 0 \le 0b=0⇒0≤0, cioè a≤ba \le ba≤b
  • se a=0a = 0a=0 e se b=1⇒0≤1b = 1 \Rightarrow 0 \le 1b=1⇒0≤1, cioè a≤ba \le ba≤b
  • se a=1a = 1a=1 e se b=1⇒1≤1b = 1 \Rightarrow 1 \le 1b=1⇒1≤1, cioè a≤ba \le ba≤b

Quindi a≤ba \le ba≤b.

Dimostrazione inversa: Ipotesi: supponiamo che in BBB valga a≤ba \le ba≤b. Tesi: devo dimostrare che vale a+b=ba + b = ba+b=b.

Gli unici elementi dell'insieme BBB sono 000 ed 111. Vale: 0≤00 \le 00≤0, 0≤10 \le 10≤1, 1≤11 \le 11≤1. Quindi si ha, considerando i casi possibili:

  • se a=0a = 0a=0 e se b=0⇒0+0=0=a+b=bb = 0 \Rightarrow 0 + 0 = 0 = a + b = bb=0⇒0+0=0=a+b=b
  • se a=0a = 0a=0 e se b=1⇒0+1=1=a+b=bb = 1 \Rightarrow 0 + 1 = 1 = a + b = bb=1⇒0+1=1=a+b=b
  • se a=1a = 1a=1 e se b=1⇒1+1=1=a+b=bb = 1 \Rightarrow 1 + 1 = 1 = a + b = bb=1⇒1+1=1=a+b=b (a=1a = 1a=1 e b=0b = 0b=0 non lo posso considerare perché contrario all'ipotesi)

Il che equivale a dire a+b=ba + b = ba+b=b, come volevamo.
