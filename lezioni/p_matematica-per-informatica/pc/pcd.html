Algebra binaria di Boole ​

Consideriamo un insieme BBB in cui siano definite un'operazione unaria indicata con ′'′ e due operazioni binarie indicate con ⊗\otimes⊗ e ⊕\oplus⊕ che agiscano su due oggetti distinti 000 e 111.

{B,′,⊗,⊕;0,1}\{ B, ', \otimes, \oplus; 0, 1 \} {B,′,⊗,⊕;0,1}

Chiamiamo a,b,c,d,…a, b, c, d, \dotsa,b,c,d,… degli elementi dell'insieme BBB.

Nota: Quindi aaa può essere 000 o 111, bbb può essere 000 o 111, ccc può essere 000 o 111, ddd può essere 000 o 111, eccetera.

Questo insieme è detto algebra di Boole se valgono le seguenti leggi:

  • Legge commutativa

    a⊕b=b⊕aa \oplus b = b \oplus a a⊕b=b⊕a

    a⊗b=b⊗aa \otimes b = b \otimes a a⊗b=b⊗a

  • Legge distributiva

    a⊕(b⊗c)=(a⊕b)⊗(a⊕c)a \oplus (b \otimes c) = (a \oplus b) \otimes (a \oplus c) a⊕(b⊗c)=(a⊕b)⊗(a⊕c)

    Nota: Notare che questa è molto diversa dalle leggi per la somma normale in N\mathbb{N}N.

    a⊗(b⊕c)=(a⊗b)⊕(a⊗c)a \otimes (b \oplus c) = (a \otimes b) \oplus (a \otimes c) a⊗(b⊕c)=(a⊗b)⊕(a⊗c)

  • Leggi dell'identità

    a⊕0=aa \oplus 0 = a a⊕0=a

    Nota: Cioè 000 è l'elemento neutro per ⊕\oplus⊕.

    a⊗1=aa \otimes 1 = a a⊗1=a

    Nota: Cioè 111 è l'elemento neutro per ⊗\otimes⊗.

  • Leggi del complemento

    Nota: Significano semplicemente che se aaa vale 000 allora aˋàaˋ vale 111 e se aaa vale 111 allora aˋàaˋ vale 000.
