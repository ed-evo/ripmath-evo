Sconto composto ​

Lo sconto si dice composto quando è calcolato ad interesse composto cioè quando per ottenere il valore nominale si applica l'interesse composto alla somma scontata.

Quindi chiamando VVV la somma scontata e CCC il valore nominale avremo

C=V(1+i)tC = V(1+i)^t C=V(1+i)t

Ricaviamo il valore attuale VVV

V=C(1+i)tV = \frac{C}{(1+i)^t} V=(1+i)tC​

pongo

1(1+i)t=(1+i)−t=vt\frac{1}{(1+i)^t} = (1+i)^{-t} = v^t (1+i)t1​=(1+i)−t=vt

e quindi ottengo la formula

V=CvtV = C v^t V=Cvt

Questa formula è molto importante: essa ti mostra che per portare indietro nel tempo il capitale CCC e farlo diventare il valore attuale VVV, nel regime ad interesse semplice, basta dividerlo per il fattore (1+it)(1+it)(1+it) od anche moltiplicarlo per 1/(1+it)=(1+it)−11/(1+it) = (1+it)^{-1}1/(1+it)=(1+it)−1.

(1+it)−1=vt(1+it)^{-1} = v^t (1+it)−1=vt

si chiama fattore di sconto composto.

Il fattore vtv^tvt ci permetterà di spostare indietro nel tempo i capitali a regime di interesse composto.

Se ora voglio ricavare lo sconto basterà sottrarre dal valore nominale il valore attuale

S=C−V=C−C(1+i)−t=C−CvtS = C - V = C - C(1+i)^{-t} = C - Cv^t S=C−V=C−C(1+i)−t=C−Cvt

e raccogliendo CCC ottengo la formula finale

S=C(1−vt)S = C(1 - v^t) S=C(1−vt)

Negli esercizi per calcolare lo sconto conviene prima calcolare il valore attuale con la formula V=CvtV = Cv^tV=Cvt e poi fare la differenza S=C−VS = C - VS=C−V.

Per utilizzare la formula V=CvtV = Cv^tV=Cvt si può ricorrere ai logaritmi: cioè passando ai logaritmi avremo

log⁡V=log⁡C+log⁡(1+i)−t=log⁡C−tlog⁡(1+i)=log⁡C+tCoLog(1+i)\log V = \log C + \log (1+i)^{-t} = \log C - t \log(1+i) = \log C + t \text{CoLog}(1+i) logV=logC+log(1+i)−t=logC−tlog(1+i)=logC+tCoLog(1+i)
