Area di un quadrilatero qualunque ​

Chiamiamo OOO l'intersezione delle due diagonali e poniamo: AC‾=d1BD‾=d2\overline{AC} = d_1 \quad \overline{BD} = d_2AC=d1​BD=d2​

Poniamo inoltre: AO‾=pOC‾=qBO‾=mOD‾=n\overline{AO} = p \quad \overline{OC} = q \quad \overline{BO} = m \quad \overline{OD} = nAO=pOC=qBO=mOD=nBOA^=COD^=Θ\widehat{BOA} = \widehat{COD} = \ThetaBOA=COD=ΘAOD^=BOC^=180∘−Θ\widehat{AOD} = \widehat{BOC} = 180^\circ - \ThetaAOD=BOC=180∘−Θ

Per trovare l'area totale facciamo la somma delle aree dei vari triangoli componenti il quadrilatero: As(ABCD)=As(AOB)+As(BOC)+As(COD)+As(DOA)A_s(ABCD) = A_s(AOB) + A_s(BOC) + A_s(COD) + A_s(DOA)As​(ABCD)=As​(AOB)+As​(BOC)+As​(COD)+As​(DOA)

Utilizziamo per trovare l'area dei triangoli la formula trovata all'inizio del capitolo:

As(ABCD)=12pmsin⁡Θ+12mqsin⁡(180∘−Θ)+12qnsin⁡Θ+12npsin⁡(180∘−Θ)A_s(ABCD) = \frac{1}{2}pm \sin \Theta + \frac{1}{2}mq \sin (180^\circ - \Theta) + \frac{1}{2}qn \sin \Theta + \frac{1}{2}np \sin (180^\circ - \Theta) As​(ABCD)=21​pmsinΘ+21​mqsin(180∘−Θ)+21​qnsinΘ+21​npsin(180∘−Θ)

Ricordando che sin⁡(180∘−Θ)=sin⁡Θ\sin(180^\circ - \Theta) = \sin \Thetasin(180∘−Θ)=sinΘ avremo:

As(ABCD)=12pmsin⁡Θ+12mqsin⁡Θ+12qnsin⁡Θ+12npsin⁡ΘA_s(ABCD) = \frac{1}{2}pm \sin \Theta + \frac{1}{2}mq \sin \Theta + \frac{1}{2}qn \sin \Theta + \frac{1}{2}np \sin \Theta As​(ABCD)=21​pmsinΘ+21​mqsinΘ+21​qnsinΘ+21​npsinΘ

Prima metto in evidenza i fattori comuni:

As(ABCD)=12sin⁡Θ(pm+mq+qn+np)A_s(ABCD) = \frac{1}{2} \sin \Theta (pm + mq + qn + np) As​(ABCD)=21​sinΘ(pm+mq+qn+np)

Dentro parentesi posso raccogliere a fattor comune parziale:

=12sin⁡Θ[m(p+q)+n(p+q)]= \frac{1}{2} \sin \Theta [m(p + q) + n(p + q)] =21​sinΘ[m(p+q)+n(p+q)]

=12sin⁡Θ(p+q)(m+n)= \frac{1}{2} \sin \Theta (p + q)(m + n) =21​sinΘ(p+q)(m+n)

Essendo p+q=d1p + q = d_1p+q=d1​ e m+n=d2m + n = d_2m+n=d2​ otteniamo la formula finale:

As(ABCD)=12d1d2sin⁡Θ\textcolor{red}{A_s(ABCD) = \frac{1}{2} d_1 d_2 \sin \Theta} As​(ABCD)=21​d1​d2​sinΘ

Cioè:

[L'area di un quadrilatero è data dal semiprodotto delle diagonali per il seno dell'angolo compreso fra le diagonali stesse]
