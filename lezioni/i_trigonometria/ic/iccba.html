Equazioni in seno e coseno di primo grado lineari omogenee ​

Lineare significa che i termini dell'equazione, diversi dal termine noto, sono tutti di primo grado Omogenea significa che il termine noto vale 000

Per risolvere un'equazione di questo genere è sufficiente dividere tutti i termini dell'equazione per cos⁡x\cos xcosx, supponendo che cos⁡x\cos xcosx sia diverso da zero: in tal modo si ottiene un'equazione di primo grado in tan⁡x\tan xtanx che si risolve normalmente.

È necessario però controllare che la soluzione corrispondente a cos⁡x=0\cos x = 0cosx=0 non sia valida per l'equazione di partenza.

Un esempio chiarirà meglio il concetto.

Risolvere l'equazione sen x+cos⁡x=0\textcolor{blue}{\text{sen } x + \cos x = 0}sen x+cosx=0

Divido ogni termine per cos⁡x\cos xcosx supponendo cos⁡x≠0\textcolor{red}{\cos x \neq 0}cosx=0 (secondo principio di equivalenza delle equazioni)

sen xcos⁡x+cos⁡xcos⁡x=0cos⁡x\frac{\textcolor{red}{\text{sen } x}}{\textcolor{red}{\cos x}} + \frac{\textcolor{red}{\cos x}}{\textcolor{red}{\cos x}} = \frac{\textcolor{red}{0}}{\textcolor{red}{\cos x}} cosxsen x​+cosxcosx​=cosx0​

Ricordando la seconda relazione fondamentale: tan⁡x+1=0\textcolor{red}{\tan x + 1 = 0}tanx+1=0

Risolvo: tan⁡x=−1\textcolor{red}{\tan x = -1}tanx=−1

Il valore dell'angolo corrispondente è 135∘135^\circ135∘

(Sarebbe −45∘-45^\circ−45∘ ma noi considereremo sempre gli angoli partendo dall'origine degli angoli e ruotando in senso antiorario)

Quindi abbiamo x∘=135∘+k⋅180∘\textcolor{red}{x^\circ = 135^\circ + k \cdot 180^\circ}x∘=135∘+k⋅180∘ o preferibilmente x=34π+kπ\textcolor{red}{x = \frac{3}{4}\pi + k\pi}x=43​π+kπ

Non è finita! Siccome ho supposto cos⁡x≠0\textcolor{red}{\cos x \neq 0}cosx=0 devo controllare se la soluzione cos⁡x=0\cos x = 0cosx=0 soddisfa l'equazione di partenza: siccome cos⁡x=0\cos x = 0cosx=0 si ottiene nel primo giro per gli angoli 90∘90^\circ90∘ e 270∘270^\circ270∘, devo controllare i valori dell'equazione sen x+cos⁡x=0\textcolor{red}{\text{sen } x + \cos x = 0}sen x+cosx=0 a 90∘90^\circ90∘ ed a 270∘270^\circ270∘

  • Controllo per x=90∘x = 90^\circx=90∘ (se vuoi essere preciso usa π/2\pi/2π/2) sen 90∘+cos⁡90∘=0\textcolor{red}{\text{sen } 90^\circ + \cos 90^\circ = 0}sen 90∘+cos90∘=01+0=0\textcolor{red}{1 + 0 = 0}1+0=0 x=90∘x = 90^\circx=90∘ non è soluzione
  • Controllo per x=270∘x = 270^\circx=270∘ (se vuoi essere preciso usa 3π/23\pi/23π/2) sen 270∘+cos⁡270∘=0\textcolor{red}{\text{sen } 270^\circ + \cos 270^\circ = 0}sen 270∘+cos270∘=0−1+0=0\textcolor{red}{-1 + 0 = 0}−1+0=0 x=270∘x = 270^\circx=270∘ non è soluzione

Quindi la soluzione finale è x∘=135∘+k⋅180∘\textcolor{blue}{x^\circ = 135^\circ + k \cdot 180^\circ}x∘=135∘+k⋅180∘ o meglio x=34π+kπ\textcolor{blue}{x = \frac{3}{4}\pi + k\pi}x=43​π+kπ

È un errore piuttosto comune e diffuso non controllare le condizioni di realtà; se dividi per un'espressione e il tuo risultato differisce dal libro di testo controlla subito se hai considerato i casi in cui il denominatore vale zero.
