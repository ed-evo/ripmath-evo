Equazioni in seno e coseno di secondo grado lineari non omogenee ​

Per risolvere equazioni di questo genere basta ricordare la prima relazione fondamentale: prenderemo il termine noto e lo moltiplicheremo per [$$\sin^2 x + \cos^2 x$]{.text-blue} in questo modo l'equazione si trasforma in omogenea e la risolviamo come nella pagina precedente.

Un esempio chiarirà meglio il concetto.

Risolvere l'equazione:

[$$2 \sin x \cos x - \sin^2 x - \cos^2 x = -2$]

moltiplico il termine noto per sin⁡2x+cos⁡2x\sin^2 x + \cos^2 xsin2x+cos2x

[2sin⁡xcos⁡x−sin⁡2x−cos⁡2x=−2(sin⁡2x+cos⁡2x)2 \sin x \cos x - \sin^2 x - \cos^2 x = -2(\sin^2 x + \cos^2 x)2sinxcosx−sin2x−cos2x=−2(sin2x+cos2x)]{.text-red} [$$2 \sin x \cos x - \sin^2 x - \cos^2 x = -2\sin^2 x - 2\cos^2 x$]

porto tutti i termini prima dell'uguale:

[$$2 \sin x \cos x - \sin^2 x - \cos^2 x + 2\sin^2 x + 2\cos^2 x = 0$]

sommo i termini simili ed ordino rispetto a sin⁡x\sin xsinx:

[$$\sin^2 x + 2 \sin x \cos x + \cos^2 x = 0$]

divido ogni termine per cos⁡2x\cos^2 xcos2x supponendo [$$\cos x \neq 0$]

sin⁡2xcos⁡2x+2sin⁡xcos⁡xcos⁡2x+cos⁡2xcos⁡2x=0cos⁡2x\frac{\sin^2 x}{\cos^2 x} + \frac{2 \sin x \cos x}{\cos^2 x} + \frac{\cos^2 x}{\cos^2 x} = \frac{0}{\cos^2 x} cos2xsin2x​+cos2x2sinxcosx​+cos2xcos2x​=cos2x0​

Applico la seconda relazione fondamentale:

[$$\tan^2 x + 2 \tan x + 1 = 0$]

È un'equazione di secondo grado nell'incognita tan⁡x\tan xtanx: applico la formula risolutiva.

veramente, se l'osservi bene si può risolvere in modo più semplice

tan⁡x=−2±4−42\tan x = \frac{-2 \pm \sqrt{4 - 4}}{2} tanx=2−2±4−4​​

potevamo usare la formula ridotta

otteniamo:

[$$\tan x = -1$]

Il valore dell'angolo corrispondente a tan⁡x=1\tan x = 1tanx=1 è 45∘45^\circ45∘. Quindi abbiamo:

[$$x = -45^\circ + k 180^\circ$]

o preferibilmente:

[$$x = -\frac{\pi}{4} + k\pi$]

Non è finita! Siccome ho supposto [cos⁡x≠0\cos x \neq 0cosx=0]{.text-red} devo controllare se la soluzione$\cos x = 0$soddisfa l'equazione di partenza: siccome$\cos x = 0$si ottiene nel primo giro per gli angoli$90^\circ$e$270^\circ$$ devo controllare i valori dell'equazione:

[$$2 \sin x \cos x - \sin^2 x - \cos^2 x = -2$]

a 90∘90^\circ90∘ ed a 270∘270^\circ270∘:

  • Controllo per x=90∘x = 90^\circx=90∘ (se vuoi essere preciso usa π/2\pi/2π/2): [2sin⁡90∘cos⁡90∘−sin⁡290∘−cos⁡290∘=−22 \sin 90^\circ \cos 90^\circ - \sin^2 90^\circ - \cos^2 90^\circ = -22sin90∘cos90∘−sin290∘−cos290∘=−2]{.text-red} [−1=2-1 = 2−1=2]{.text-red} \quad x=90∘x = 90^\circx=90∘ non è soluzione
  • Controllo per x=270∘x = 270^\circx=270∘ (se vuoi essere preciso usa 3π/23\pi/23π/2): [2sin⁡270∘cos⁡270∘−sin⁡2270∘−cos⁡2270∘=−22 \sin 270^\circ \cos 270^\circ - \sin^2 270^\circ - \cos^2 270^\circ = -22sin270∘cos270∘−sin2270∘−cos2270∘=−2]{.text-red} [−1=2-1 = 2−1=2]{.text-red} \quad x=270∘x = 270^\circx=270∘ non è soluzione

Quindi la soluzione finale è:

[$$x = -45^\circ + k 180^\circ$]
