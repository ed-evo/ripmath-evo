Area di un quadrilatero qualunque ​

Chiamiamo OOO l'intersezione delle due diagonali e poniamo: AC‾=d1BD‾=d2\overline{AC} = d_1 \quad \overline{BD} = d_2​AC​​​=d​1​​​BD​​​=d​2​​

Poniamo inoltre: AO‾=pOC‾=qBO‾=mOD‾=n\overline{AO} = p \quad \overline{OC} = q \quad \overline{BO} = m \quad \overline{OD} = n​AO​​​=p​OC​​​=q​BO​​​=m​OD​​​=n \widehat{BOA} = \widehat{COD} = \Theta \widehat{AOD} = \widehat{BOC} = 180^\circ - \Theta

Per trovare l'area totale facciamo la somma delle aree dei vari triangoli componenti il quadrilatero: As(ABCD)=As(AOB)+As(BOC)+As(COD)+As(DOA)A_s(ABCD) = A_s(AOB) + A_s(BOC) + A_s(COD) + A_s(DOA)A​s​​(ABCD)=A​s​​(AOB)+A​s​​(BOC)+A​s​​(COD)+A​s​​(DOA)

Utilizziamo per trovare l'area dei triangoli la formula trovata all'inizio del capitolo:

As(ABCD)=12pmsinΘ+12mqsin(180∘−Θ)+12qnsinΘ+12npsin(180∘−Θ)A_s(ABCD) = \frac{1}{2}pm \sin \Theta + \frac{1}{2}mq \sin (180^\circ - \Theta) + \frac{1}{2}qn \sin \Theta + \frac{1}{2}np \sin (180^\circ - \Theta) A​s​​(ABCD)=​2​​1​​pmsinΘ+​2​​1​​mqsin(180​∘​​−Θ)+​2​​1​​qnsinΘ+​2​​1​​npsin(180​∘​​−Θ)

Ricordando che sin(180∘−Θ)=sinΘ\sin(180^\circ - \Theta) = \sin \Thetasin(180​∘​​−Θ)=sinΘ avremo:

As(ABCD)=12pmsinΘ+12mqsinΘ+12qnsinΘ+12npsinΘA_s(ABCD) = \frac{1}{2}pm \sin \Theta + \frac{1}{2}mq \sin \Theta + \frac{1}{2}qn \sin \Theta + \frac{1}{2}np \sin \Theta A​s​​(ABCD)=​2​​1​​pmsinΘ+​2​​1​​mqsinΘ+​2​​1​​qnsinΘ+​2​​1​​npsinΘ

Prima metto in evidenza i fattori comuni:

As(ABCD)=12sinΘ(pm+mq+qn+np)A_s(ABCD) = \frac{1}{2} \sin \Theta (pm + mq + qn + np) A​s​​(ABCD)=​2​​1​​sinΘ(pm+mq+qn+np)

Dentro parentesi posso raccogliere a fattor comune parziale:

=12sinΘ[m(p+q)+n(p+q)]= \frac{1}{2} \sin \Theta [m(p + q) + n(p + q)] =​2​​1​​sinΘ[m(p+q)+n(p+q)]

=12sinΘ(p+q)(m+n)= \frac{1}{2} \sin \Theta (p + q)(m + n) =​2​​1​​sinΘ(p+q)(m+n)

Essendo p+q=d1p + q = d_1p+q=d​1​​ e m+n=d2m + n = d_2m+n=d​2​​ otteniamo la formula finale:

\textcolor{red}{A_s(ABCD) = \frac{1}{2} d_1 d_2 \sin \Theta}

Cioè:

[L'area di un quadrilatero è data dal semiprodotto delle diagonali per il seno dell'angolo compreso fra le diagonali stesse]
