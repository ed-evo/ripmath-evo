# [Terza figura]{.text-red}

$$
\text{Premessa maggiore} + \text{Premessa minore} = \text{Conclusione}
$$

Indico:
- $$(M -- A)$$ la premessa maggiore
- $$(M -- B)$$ la premessa minore
- $$(B -- A)$$ la conclusione

Considerando i predicati avremo la terza figura quando il termine medio compare al primo ed al terzo posto, cioè:

$$
\textcolor{red}{(M -- A) + (M -- B) = (B -- A)}
$$

Come esempio consideriamo il sillogismo:
- **Qualche parallelogramma è un quadrato**
- Qualche parallelogramma è un rettangolo
- **Qualche rettangolo è un quadrato**

Che nei particolari diventa:

$$
(x \text{ è un parallelogramma } \textcolor{red}{M}) -- (x \text{ è un quadrato } \textcolor{red}{A}) +
$$
$$
(x \text{ è un parallelogramma } \textcolor{red}{M}) -- (x \text{ è un rettangolo } \textcolor{red}{B}) =
$$
$$
(x \text{ è un rettangolo } \textcolor{red}{B}) -- (x \text{ è un quadrato } \textcolor{red}{A})
$$
