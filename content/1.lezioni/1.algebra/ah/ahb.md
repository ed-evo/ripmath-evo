# Vocabolario

Proviamo a risolvere un semplice problema:

> [Il triplo di un numero è uguale al doppio del numero stesso aumentato di $$4$$. Trovare il numero]{.text-red}

Questo si può tradurre termine a termine in un'equazione:

> Intanto il numero da trovare lo chiameremo $$\textcolor{red}{x}$$
>
> Il triplo ($$\textcolor{red}{3}$$)
>
> di ($$\textcolor{red}{\cdot}$$)
>
> un numero ($$\textcolor{red}{x}$$)
>
> è uguale ($$\textcolor{red}{=}$$)
>
> al doppio ($$\textcolor{red}{2}$$)
>
> del ($$\textcolor{red}{\cdot}$$)
>
> numero stesso ($$\textcolor{red}{x}$$)
>
> aumentato ($$\textcolor{red}{+}$$)
>
> di $$4$$ ($$\textcolor{red}{4}$$)

L'equazione

$$
\textcolor{red}{3 \cdot x = 2 \cdot x + 4}
$$

è la traduzione in equazione del problema precedente.

È quindi possibile costruire una specie di vocabolario che ci permetta di tradurre un problema in "matematichese". Cominciamo a costruirlo con i dati che abbiamo e man mano che troveremo termini nuovi li aggiungeremo.

Come indicazione di sintassi occorre aggiungere che in matematica si legge prima l'operazione poi i due termini, così se devo leggere

$$\textcolor{red}{3x - 2}$$

leggerò

[la differenza fra il triplo di un numero e $$2$$]{.text-red}

## [Vocabolario]{.text-blue}

| [Termine]{.text-blue} | [Simbolo/Espressione]{.text-blue} |
| :--- | :--- |
| ente da trovare | $$\textcolor{blue}{x}$$ |
| di | $$\textcolor{blue}{\cdot}$$ |
| aumentato, sommato | $$\textcolor{blue}{+}$$ |
| differisce, diminuito | $$\textcolor{blue}{-}$$ |
| vale, è uguale a | $$\textcolor{blue}{=}$$ |
| supera di $$5$$ | $$\textcolor{blue}{= 5 +}$$ |
| differisce di $$5$$ da qualcosa | $$\textcolor{blue}{= \text{qualcosa} - 5}$$ |
| antecedente | $$\textcolor{blue}{x - 1}$$ |
| seguente, successivo | $$\textcolor{blue}{x + 1}$$ |
| dividendo $$a$$ per $$b$$ ottengo come quoziente $$c$$ e come resto $$d$$ | $$\textcolor{blue}{a = b \cdot c + d}$$ <br> $$\textcolor{blue}{\text{dividendo} = \text{divisore} \cdot \text{quoziente} + \text{resto}}$$ |
| somma tra qualcosa e qualcos'altro | $$\textcolor{blue}{\text{qualcosa} + \text{qualcos'altro}}$$ |
| differenza tra qualcosa e qualcos'altro | $$\textcolor{blue}{\text{qualcosa} - \text{qualcos'altro}}$$ |
| dividere un numero in due parti | $$\textcolor{blue}{\text{prima parte } x}$$ <br> $$\textcolor{blue}{\text{seconda parte } \text{numero} - x}$$ |
| il rapporto di due numeri è $$a/b$$ | $$\textcolor{blue}{\text{primo numero } ax}$$ <br> $$\textcolor{blue}{\text{secondo numero } bx}$$ |
| somma di due numeri è $$a$$ | $$\textcolor{blue}{\text{primo numero } x}$$ <br> $$\textcolor{blue}{\text{secondo numero } a - x}$$ |
