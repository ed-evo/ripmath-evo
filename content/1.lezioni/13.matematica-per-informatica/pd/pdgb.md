# [circuito **somma binaria**]{.text-red}

Mostriamo come funziona il circuito **somma binaria**

I casi possibili sono:

- $$0 + 0 = 00$$
- $$0 + 1 = 01$$
- $$1 + 0 = 01$$
- $$1 + 1 = 10$$

Cioè:

| input $$a$$ | input $$b$$ | somma |
| :---: | :---: | :---: |
| $$0$$ | $$0$$ | $$00$$ |
| $$0$$ | $$1$$ | $$01$$ |
| $$1$$ | $$0$$ | $$01$$ |
| $$1$$ | $$1$$ | $$10$$ |

Come volevamo
