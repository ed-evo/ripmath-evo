# [grafico della funzione $$y = \frac{2}{x} + 3 + \frac{1}{2}x$$]{.text-red}

Presa la funzione
$$
y = \frac{2}{x} + 3 + \frac{1}{2}x
$$
pensiamola come
$$
y = y_1 + y_2 = \left(\frac{2}{x}\right) + \left(3 + \frac{1}{2}x\right)
$$
quindi basterà fare il grafico delle $$2$$ funzioni:
- [$$y_1 = \frac{2}{x}$$]{.text-red} (Iperbole riferita ai propri assi)
- [$$y_2 = \frac{1}{2}x + 3$$]{.text-blue} (retta)

e poi sommare algebricamente punto per punto i valori delle ordinate trovate.

Troviamo alcuni punti per meglio disegnare il grafico:

- [funzione $$y_1 = \frac{2}{x}$$]{.text-red}
  facciamo una tabella di valori:

  | [$$x$$]{.text-red} | [$$y_1$$]{.text-red} |
  | :---: | :---: |
  | $$\frac{1}{2}$$ | $$4$$ |
  | $$1$$ | $$2$$ |
  | $$2$$ | $$1$$ |
  | $$4$$ | $$\frac{1}{2}$$ |
  | $$-\frac{1}{2}$$ | $$-4$$ |
  | $$-1$$ | $$-2$$ |
  | $$-2$$ | $$-1$$ |
  | $$-4$$ | $$-\frac{1}{2}$$ |

- [funzione $$y_2 = \frac{1}{2}x + 3$$]{.text-blue}
  Anche se per disegnare la retta sarebbero sufficienti due punti, per meglio mostrare come si deve fare facciamo una tabella con le stesse ascisse della tabella precedente:

  | [$$x$$]{.text-blue} | [$$y_2$$]{.text-blue} |
  | :---: | :---: |
  | $$\frac{1}{2}$$ | $$\frac{13}{4}$$ |
  | $$1$$ | $$\frac{7}{2}$$ |
  | $$2$$ | $$4$$ |
  | $$4$$ | $$5$$ |
  | $$-\frac{1}{2}$$ | $$\frac{11}{4}$$ |
  | $$-1$$ | $$\frac{5}{2}$$ |
  | $$-2$$ | $$2$$ |
  | $$-4$$ | $$1$$ |

- Ora basta sovrapporre i due grafici e fare la somma algebrica punto per punto:

  | $$x$$ | [$$y_1$$]{.text-red} | $+$ | [$$y_2$$]{.text-blue} | $$y$$ |
  | :---: | :---: | :---: | :---: | :---: |
  | $$\frac{1}{2}$$ | $$4$$ | $+$ | $$\frac{13}{4}$$ | $$\frac{29}{4}$$ |
  | $$1$$ | $$2$$ | $+$ | $$\frac{7}{2}$$ | $$\frac{11}{2}$$ |
  | $$2$$ | $$1$$ | $+$ | $$4$$ | $$5$$ |
  | $$4$$ | $$\frac{1}{2}$$ | $+$ | $$5$$ | $$\frac{11}{2}$$ |
  | $$-\frac{1}{2}$$ | $$-4$$ | $+$ | $$\frac{11}{4}$$ | $$-\frac{5}{4}$$ |
  | $$-1$$ | $$-2$$ | $+$ | $$\frac{5}{2}$$ | $$\frac{1}{2}$$ |
  | $$-2$$ | $$-1$$ | $+$ | $$2$$ | $$1$$ |
  | $$-4$$ | $$-\frac{1}{2}$$ | $+$ | $$1$$ | $$\frac{1}{2}$$ |

  in nero la curva risultante.

> **Nota:** di solito si preferisce tracciare le curve componenti e poi, senza fare troppi calcoli, mettere intuitivamente per qualche punto la somma algebrica dei punti sulla stessa verticale fino a capire come si sviluppa il grafico e quindi lo si disegna.
