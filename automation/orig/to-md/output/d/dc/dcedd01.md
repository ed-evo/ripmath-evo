# [Calcoli]{.text-red}

> Io eseguo tutti i passaggi, tu puoi abbreviare

$$
\textcolor{blue}{
\begin{cases} 
2x - y - 8 = 0 \\ 
2x + 3y = 0 
\end{cases}
}
$$

Risolviamo per sostituzione; ricavo $y$ dalla prima equazione

$$
\textcolor{blue}{
\begin{cases} 
-y = 8 - 2x \\ 
2x + 3y = 0 
\end{cases}
}
$$

Cambio di segno

$$
\textcolor{blue}{
\begin{cases} 
y = 2x - 8 \\ 
2x + 3y = 0 
\end{cases}
}
$$

Sostituisco

$$
\textcolor{blue}{
\begin{cases} 
y = 2x - 8 \\ 
2x + 3(2x-8) = 0 
\end{cases}
}
$$

$$
\textcolor{blue}{
\begin{cases} 
\dots \\ 
2x + 6x - 24 = 0 
\end{cases}
}
$$

$$
\textcolor{blue}{
\begin{cases} 
\dots \\ 
8x = 24 
\end{cases}
}
$$

$$
\textcolor{blue}{
\begin{cases} 
y = 2x - 8 \\ 
x = 24/8 = 3 
\end{cases}
}
$$

$$
\textcolor{blue}{
\begin{cases} 
y = 2 \cdot 3 - 8 \\ 
x = 3 
\end{cases}
}
$$

$$
\textcolor{blue}{
\begin{cases} 
y = -2 \\ 
x = 3 
\end{cases}
}
$$

Risultato

$$
\textcolor{blue}{
\begin{cases} 
x = 3 \\ 
y = -2 
\end{cases}
}
$$
