# <span class="text-red-600">Parabola tangente all'asse delle x</span>

È equivalente al caso ove il $\Delta$ del polinomio è uguale a zero (2 soluzioni reali coincidenti = 2 punti coincidenti, cioè un solo punto sull'asse x).

Distinguiamo i due casi:
- $a > 0$
- $a < 0$

---

## $a > 0$

Se $a$ è maggiore di zero la parabola ha la concavità verso l'alto, quindi avremo che il trinomio è positivo per tutti i valori eccetto il valore del vertice $-\frac{b}{2a}$ per cui si annulla.

| Condizioni | $\textcolor{blue}{ax^2 + bx + c > 0}$ | $\textcolor{blue}{ax^2 + bx + c < 0}$ |
| :--- | :--- | :--- |
| $\textcolor{blue}{\Delta = 0}$<br>$\textcolor{blue}{a > 0}$ | <span class="text-red-500">tutti i valori eccetto $-\frac{b}{2a}$ per cui si annulla</span> | <span class="text-red-500">nessun valore</span> |

---

## $a < 0$

Se $a$ è minore di zero la parabola ha la concavità verso il basso, quindi avremo che il trinomio è negativo per tutti i valori eccetto il valore del vertice $-\frac{b}{2a}$ per cui si annulla.

| Condizioni | $\textcolor{blue}{ax^2 + bx + c > 0}$ | $\textcolor{blue}{ax^2 + bx + c < 0}$ |
| :--- | :--- | :--- |
| $\textcolor{blue}{\Delta = 0}$<br>$\textcolor{blue}{a < 0}$ | <span class="text-red-500">nessun valore</span> | <span class="text-red-500">tutti i valori eccetto $-\frac{b}{2a}$ per cui si annulla</span> |
