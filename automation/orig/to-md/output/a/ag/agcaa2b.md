Per calcolare il segno dell'espressione
$\textcolor{blue}{(x+2)(x-3) < 0}$
devi fare il prodotto dei segni di $\textcolor{blue}{(x+2)}$ e di $\textcolor{blue}{(x-3)}$.
Le pongo entrambe maggiori di zero.

---

Porre $\textcolor{blue}{(x+2) > 0}$ equivale a dire $\textcolor{blue}{x > -2}$
Porre $\textcolor{blue}{(x-3) > 0}$ equivale a dire $\textcolor{blue}{x > 3}$

---

| | | |
| :--- | :---: | :---: |
| $\textcolor{blue}{x > -2}$ | $\textcolor{blue}{---}$ | $\textcolor{blue}{(-2) +++++++++}$ |
| $\textcolor{blue}{x > 3}$ | $\textcolor{blue}{---}$ | $\textcolor{blue}{(3) +++++}$ |
| $f(x)$ | $+++++$ | $(-2) ----- (3) +++++$ |

---

> per $\textcolor{blue}{x < -2}$ abbiamo $\textcolor{blue}{x + 2}$ negativa e $\textcolor{blue}{x - 3}$ negativa quindi il loro prodotto $\textcolor{blue}{f(x) = (x + 2)(x - 3)}$ è positivo (meno per meno fa più)

---

> per $\textcolor{blue}{-2 < x < 3}$ abbiamo $\textcolor{blue}{x + 2}$ positiva e $\textcolor{blue}{x - 3}$ negativa quindi il loro prodotto è negativo (più per meno dà meno)

---

> per $\textcolor{blue}{x > 3}$ abbiamo $\textcolor{blue}{x + 2}$ positiva e $\textcolor{blue}{x - 3}$ positiva quindi il loro prodotto è positivo (più per più fa più)

---

Siccome devo cercare dove il prodotto $\textcolor{blue}{f(x) = (x + 2)(x - 3)}$ risulta minore di zero allora la soluzione sarà $\textcolor{blue}{-2 < x < 3}$.
