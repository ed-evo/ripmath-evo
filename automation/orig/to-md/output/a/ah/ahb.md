# Vocabolario

> Proviamo a risolvere un semplice problema:
> <span class="text-red-600">Il triplo di un numero è uguale al doppio del numero stesso aumentato di 4. Trovare il numero</span>
>
> Questo si può tradurre termine a termine in un'equazione:
>
> Intanto il numero da trovare lo chiameremo $x$
> Il triplo ($3$)
> di ($\cdot$)
> un numero ($x$)
> è uguale ($=$)
> al doppio ($2$)
> del ($\cdot$)
> numero stesso ($x$)
> aumentato ($+$)
> di 4 ($4$)
>
> L'equazione:
> $$
> 3 \cdot x = 2 \cdot x + 4
> $$
> è la traduzione in equazione del problema precedente.

È quindi possibile costruire una specie di vocabolario che ci permetta di tradurre un problema in "matematichese". Cominciamo a costruirlo con i dati che abbiamo e man mano che troveremo termini nuovi li aggiungeremo.

Come indicazione di sintassi occorre aggiungere che in matematica si legge prima l'operazione poi i due termini, così se devo leggere
$3x - 2$
leggerò
<span class="text-red-600">la differenza fra il triplo di un numero e 2</span>

## Vocabolario

| Descrizione | Traduzione Matematica |
| :--- | :--- |
| trovare un numero | $x$ |
| numero pari | $2x$ |
| numero dispari | $2x + 1$ |
| di, del, dello, della | $\cdot$ (prodotto) |
| il doppio di un numero | $2 \cdot x$ |
| il triplo di un numero | $3 \cdot x$ |
| la metà di un numero | $1/2 \cdot x$ |
| la terza parte di un numero | $1/3 \cdot x$ |
| che, il quale | $x$ |
| somma | $+$ |
| aumentato di $a$ | $+ a$ |
| differenza | $-$ |
| diminuito di $a$ | $- a$ |
| è, vale, è uguale a, misura... (verbo in genere) | $=$ |
| supera di 5 | $= 5 +$ |
| differisce di 5 da qualcosa | $= \text{qualcosa} - 5$ |
| antecedente | $x - 1$ |
| seguente, successivo | $x + 1$ |
| numeri consecutivi | $x, x + 1$ oppure $x - 1, x$ |
| dividendo $a$ per $b$ ottengo come quoziente $c$ e come resto $d$ | $a = b \cdot c + d$ <br> $\text{dividendo} = \text{divisore} \cdot \text{quoziente} + \text{resto}$ |
| somma tra qualcosa e qualcos'altro | $\text{qualcosa} + \text{qualcos'altro}$ |
| differenza tra qualcosa e qualcos'altro | $\text{qualcosa} - \text{qualcos'altro}$ |
| dividere un numero $a$ in due parti | $\text{prima parte } x, \text{ seconda parte } a - x$ |
| la differenza fra due numeri è $a$ | $\text{primo numero } x, \text{ secondo numero } x + a$ <br> oppure $x - y = a$ |
| il rapporto di due numeri è $a/b$ | $\text{primo numero } ax, \text{ secondo numero } bx$ |
| somma di due numeri è $a$ | $\text{primo numero } x, \text{ secondo numero } a - x$ <br> oppure $x + y = a$ |
| numero composto da due cifre | $10x + y$ <br> $\text{decine più unità}$ |
