# [Grafico della funzione esponenziale quando la base è maggiore di 1]{.text-red}

Costruiamo il grafico considerando la base $2$: infatti quando la base è maggiore di $1$ tutte le curve ottenute con qualunque base hanno le stesse caratteristiche.

Voglio costruire il grafico della funzione
$\textcolor{blue}{y = 2^x}$
Lo costruiamo per punti: diamo dei valori alla $x$ ed otteniamo la $y$;

| $\textcolor{blue}{x}$ | $\textcolor{blue}{y}$ |
| :---: | :---: |
| $\textcolor{red}{4}$ | $\textcolor{red}{16}$ |
| $\textcolor{red}{3}$ | $\textcolor{red}{8}$ |
| $\textcolor{red}{2}$ | $\textcolor{red}{4}$ |
| $\textcolor{red}{1}$ | $\textcolor{red}{2}$ |
| $\textcolor{red}{0}$ | $\textcolor{red}{1}$ |
| $\textcolor{red}{-1}$ | $\textcolor{red}{1/2}$ |
| $\textcolor{red}{-2}$ | $\textcolor{red}{1/4}$ |
| $\textcolor{red}{-3}$ | $\textcolor{red}{1/8}$ |
| $\textcolor{red}{-4}$ | $\textcolor{red}{1/16}$ |

Ora metto i punti trovati in un grafico.

> **Nota:** Il punto $(4, 16)$ non è stato messo.

Ed infine li congiungo con una riga continua.

> **Conclusioni:** se la base è maggiore di $1$ l'esponenziale inizia dal valore $0$ per $x$ uguale a $\text{meno infinito}$, sale lentamente finché per $x = 0$ incontra in $1$ l'asse delle $y$ e poi cresce rapidamente verso $\text{più infinito}$ (l'esponenziale è la curva che tende a $\text{più infinito}$ più rapidamente di tutte le altre curve).

Particolarmente importante è la funzione esponenziale quando la base è il numero di Nepero $e$:

$$
\textcolor{blue}{y = e^x}
$$
