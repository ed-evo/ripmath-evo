# [Tabella delle principali derivate utilizzate nelle scuole medie superiori]{.text-red}

| [Funzione]{.text-red-darken-1} | [Derivata]{.text-red-darken-1} |
| :--- | :--- |
| $y = \text{costante}$ | $y' = 0$ |
| $y = x$ | $y' = 1$ |
| $y = x^n$ | $y' = n x^{n-1}$ |
| $y = \sqrt{x}$ | $y' = \frac{1}{2\sqrt{x}}$ |
| $y = \sin x$ | $y' = \cos x$ |
| $y = \cos x$ | $y' = -\sin x$ |
| $y = \tan x$ | $y' = \frac{1}{\cos^2 x}$ oppure $y' = 1 + \tan^2 x$ |
| $y = \cot x$ | $y' = -\frac{1}{\sin^2 x}$ |
| $y = e^x$ | $y' = e^x$ |
| $y = a^x$ | $y' = a^x \log a$ |
| $y = \log x$ | $y' = \frac{1}{x}$ |
| $y = \log_a x$ | $y' = \frac{1}{x \log a} = \frac{\log_a e}{x}$ |
| $y = \arcsin x$ | $y' = \frac{1}{\sqrt{1-x^2}}$ |
| $y = \arccos x$ | $y' = -\frac{1}{\sqrt{1-x^2}}$ |
| $y = \arctan x$ | $y' = \frac{1}{1+x^2}$ |
| $y = \text{arccot } x$ | $y' = -\frac{1}{1+x^2}$ |
